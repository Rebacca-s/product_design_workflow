# 交付物启用规则

## 核心原则

交付物不是固定全量生成的，而是根据需求类型动态启用。

每次执行 `/product-start` 时，必须先生成 `00_交付物与章节规划.md`，说明本次启用哪些交付物、不启用哪些交付物，以及原因。

---

## 默认可选交付物列表

| 编号 | 交付物 | 默认生成 | 生成条件 |
|------|--------|----------|----------|
| 00 | 交付物与章节规划 | **每次必须** | 无条件 |
| 01 | BRD 业务需求说明 | 条件生成 | 见下方 |
| 02 | 需求分析与范围定义 | 条件生成 | 见下方 |
| 03 | PRD 产品需求文档 | **每次必须** | 无条件（内容可简化） |
| 04 | PRD 专项文档 | 条件生成 | 有章节外拆时生成 |
| 05 | 原型说明文档 | 条件生成 | 见下方 |
| 06 | HTML 原型生成提示词 | 条件生成 | 见下方 |
| 07 | 研发交付检查清单 | **每次必须** | 无条件 |

---

## 各交付物启用规则

### 00_交付物与章节规划.md

**启用条件**：每次必须生成。

**作用**：记录本次需求的类型识别结果、启用的交付物列表、启用的 PRD 章节列表，以及每项启用/不启用的原因。

**输出格式**：

```markdown
# 交付物与章节规划 — [需求名称]

## 1. 原始需求
[保留用户原始需求文本]

## 2. 需求类型判断
[需求类型识别结果表格]

## 3. 交付物启用规划

| 编号 | 交付物 | 启用 | 原因 |
|------|--------|------|------|
| 00 | 交付物与章节规划 | 是 | 每次必须 |
| 01 | BRD 业务需求说明 | 是/否 | [原因] |
| ... | ... | ... | ... |

## 4. PRD 章节启用规划

| 章节 ID | 章节名称 | 启用 | 原因 |
|----------|----------|------|------|
| ... | ... | 是/否 | [原因] |

## 5. 预计外拆章节

| 章节 ID | 章节名称 | 预计外拆原因 |
|----------|----------|-------------|
| ... | ... | [原因] |

## 6. 本地业务上下文与前端项目检查

| 检查项 | 结果 |
|--------|------|
| 是否命中已有产品上下文 | 是 / 否 |
| 使用的产品上下文路径 | context/products/xxx |
| 是否存在本地前端项目 | 是 / 否 |
| 本地前端项目路径 | local_projects/frontend/xxx |
| 本次是否需要修改前端代码 | 是 / 否 |
| 如果不修改，原因 | 默认 product-start 只生成产品交付物，不修改代码 |
```

### 01_BRD_业务需求说明.md

**启用条件**：满足以下任一条件时生成。
- 新产品需求
- 大功能需求
- 方向不明确，需要先对齐业务价值
- 业务价值需要论证和评审

**不启用条件**：
- 小迭代需求（业务价值已明确）
- 页面改版需求（不改功能逻辑）
- 纯数据统计需求（价值已明确）

**不启用时**：在 `00_交付物与章节规划.md` 中说明原因。如果 BRD 中的信息（如业务背景）需要在 PRD 中体现，可合并到 PRD 第 1 章。

**模板选择**：

| 需求类型 | 优先使用模板 |
|----------|-------------|
| AI / AIGC 项目立项 | `templates/deliverables/AIGC_BRD_8章节交付物模板.md`（含痛点 3 维评分、5 维可行性、7 红线、PoC、ROI J 型曲线） |
| 非 AI 新产品 / 大功能 | `templates/deliverables/BRD_交付物模板.md` |

**选择规则**：只要需求命中"AI 功能需求"类型，且启用了 BRD，就优先使用 AIGC BRD 模板。该模板面向老板和业务方，核心回答"为什么用 AI、值不值得做"。

---

### 02_需求分析与范围定义.md

**启用条件**：
- 新产品需求：**必须生成**（完整版）
- 大功能需求：**建议生成**（标准版）
- 小迭代需求：**可生成简化版或合并到 PRD**

**不启用条件**：
- 页面改版需求（范围明确）
- 小迭代中改动范围极小（1 个字段、1 个按钮）

**简化版规则**：
- 小迭代的简化版只需包含：用户故事（1 条）、P0 功能范围、不做什么
- 不需要完整的用户角色表、场景表

---

### 03_PRD_产品需求文档.md

**启用条件**：每次必须生成。

**简化规则**：
- 小迭代需求可使用简化模板，只包含启用的章节
- 页面改版需求侧重页面与交互说明章节
- 非 AI 需求不生成 AI 专属章节

**预设方案选择**（非强制，最终章节以 00_规划为准）：

| 需求类型 | 推荐模板 |
|----------|----------|
| 新产品 | `templates/presets/新产品模板_PRD预设.md` |
| AI 功能 | `templates/presets/AI功能模板_PRD预设.md` |
| 非 AI 功能 | `templates/presets/非AI功能模板_PRD预设.md` |
| 小迭代 | `templates/presets/小迭代模板_PRD预设.md` |
| 后台管理 | `templates/presets/后台管理功能模板_PRD预设.md` |
| 页面改版 | `templates/presets/页面改版模板_PRD预设.md` |

---

### 04_PRD_专项文档/

**启用条件**：仅当有章节满足外拆条件时生成。

**不启用时**：不创建该目录。在 `00_交付物与章节规划.md` 中标注"无章节需要外拆"。

---

### 05_原型说明文档.md

**启用条件**：满足以下任一条件时生成。
- 涉及 App 页面
- 涉及小程序页面
- 涉及 Web 页面（前台）
- 涉及后台管理页面
- 涉及 H5 页面
- 涉及多页面跳转

**不启用条件**：
- 纯后端功能（如 API 接口、数据处理）
- 纯算法服务（无 UI）
- 纯数据统计（无前端展示改动）

**不启用时**：在 `00_交付物与章节规划.md` 中说明原因。

---

### 06_HTML原型生成提示词.md

**启用条件**：满足以下全部条件时生成。
- 启用了 `05_原型说明文档.md`
- 需要生成 HTML 原型用于验证或演示

**不启用条件**：
- 已经有现成的设计稿
- 不需要 HTML 原型
- 后端/算法/数据类需求无页面

**不启用时**：在 `00_交付物与章节规划.md` 中说明原因。

---

### 07_研发交付检查清单.md

**启用条件**：每次必须生成。

**规则**：检查项要根据本次启用的交付物和章节动态生成。
- 不检查本次未启用的交付物
- 不检查本次未启用的 PRD 章节
- AI 专属章节仅在有 AI 需求时检查
