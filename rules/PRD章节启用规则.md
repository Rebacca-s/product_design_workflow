# PRD 章节启用规则

## 核心原则

PRD 章节不是固定生成的，而是根据需求类型、复杂度、是否涉及 AI、是否涉及页面、是否涉及状态流转、是否涉及权限、是否涉及数据埋点，动态装配。

任何章节都可以被启用、禁用、外拆或新增。

启用章节前必须说明启用原因。不启用章节时必须说明不启用原因。

---

## 章节分类

PRD 章节库分为三类：

| 分类 | 说明 | 章节数 |
|------|------|--------|
| A. 通用基础章节 | 大多数需求都启用，小迭代可合并简化 | 9 |
| B. 条件启用章节 | 仅在特定条件下启用 | 6 |
| C. AI 专属章节 | 仅 AI 功能需求启用 | 10 |

---

## B. 条件启用章节

### B1. 业务流程图

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及多步骤操作、多角色协作、多端协作、复杂任务流程 |
| 不启用条件 | 单页面操作、简单功能、小迭代 |
| 不启用时说明 | "本需求为简单功能/小迭代，流程简单，不单独生成流程图" |
| 外拆概率 | 高（复杂流程外拆） |

### B2. 系统流程图

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及前后端交互、异步任务、第三方服务、复杂处理链路、多系统数据流转 |
| 不启用条件 | 纯前端功能、简单 CRUD |
| 不启用时说明 | "本需求不涉及多系统交互，无需系统流程图" |
| 外拆概率 | 高 |

### B3. 状态流转

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及订单、审核、任务、支付、退款、工单等有状态的对象；对象有多个状态且状态间有流转规则 |
| 不启用条件 | 无状态对象、单一状态 |
| 不启用时说明 | "本需求不涉及状态流转" |
| 外拆概率 | 高（多状态流转外拆） |

### B4. 权限设计

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及多角色、多身份、多端口权限、数据权限、操作权限 |
| 不启用条件 | 单角色、无权限差异 |
| 不启用时说明 | "本需求不涉及多角色权限" |
| 外拆概率 | 中（多角色复杂权限外拆） |

### B5. 埋点设计

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及数据统计、转化分析、运营分析、效果追踪、用户行为分析 |
| 不启用条件 | 无数据统计需求 |
| 不启用时说明 | "本需求无需数据埋点" |
| 外拆概率 | 中（埋点超过 10 个外拆） |

### B6. 风险与依赖

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及第三方服务、政策合规、资源限制、算法不确定性、数据质量、排期风险 |
| 不启用条件 | 无特殊风险 |
| 不启用时说明 | "本需求无特殊风险与依赖" |
| 外拆概率 | 低 |

## C. AI 专属章节

> **重要**：以下所有章节仅在需求涉及大模型、AIGC、RAG、Agent、ASR、OCR、智能推荐、算法服务、Prompt、AI 工作流时才启用。非 AI 需求不得强行生成 AI 专属章节。

### C1. AI 必要性说明

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求 |
| 不启用条件 | 非 AI 需求 |
| 不启用时说明 | "本需求不涉及 AI" |
| 内容要求 | 为什么需要 AI？不用 AI 行不行？AI 解决的核心问题是什么？ |

### C2. 模型选型

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求，需要选择具体模型 |
| 不启用条件 | 非 AI 需求；或模型已在之前版本确定 |
| 内容要求 | 候选模型对比、选型结论、选型理由 |
| 外拆概率 | 高 |

### C3. AI 节点设计

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求，AI 在产品中的介入点需要明确 |
| 不启用条件 | 非 AI 需求 |
| 内容要求 | AI 在哪个环节介入？输入什么？输出什么？ |

### C4. Prompt 工程

| 启用条件 | AI 功能需求，涉及 Prompt 设计 |

| 内容要求 | Prompt 设计思路、关键 Prompt 模板、版本管理策略 |
| 外拆概率 | 高 |

### C5. AI 异常兜底

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求 |
| 不启用条件 | 非 AI 需求 |
| 内容要求 | AI 输出异常时的处理策略、降级方案 |

### C6. 效果保障

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求 |
| 不启用条件 | 非 AI 需求 |
| 内容要求 | 效果评估策略、评价标准 |
| 外拆概率 | 中 |

### C7. AI 能力边界

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | AI 功能需求 |

## 章节启用决策流程

```
需求类型识别完成
    ↓
遍历全部章节（A 通用基础 + B 条件启用 + C AI 专属）
    ↓
每个章节判断：
  ├── 通用基础章节 → 默认启用，小迭代简化
  ├── 条件启用章节 → 检查是否满足启用条件
  └── AI 专属章节 → 仅 AI 需求时检查
    ↓
输出章节启用规划表
    ↓
在 00_交付物与章节规划.md 中记录
```
