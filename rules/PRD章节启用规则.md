# PRD 章节启用规则

## 核心原则

PRD 章节不是固定生成的，而是根据需求类型、复杂度、是否涉及 AI、是否涉及页面、是否涉及状态流转、是否涉及权限、是否涉及数据埋点，动态装配。

任何章节都可以被启用、禁用、外拆或新增。

启用章节前必须说明启用原因。不启用章节时必须说明不启用原因。

---

## 章节启用决策优先级

需求类型识别和 PRD 章节动态配置不是同一层逻辑：

- **需求类型识别**：负责判断本次需求大概属于什么类型，并给出交付物和章节的**初始推荐**。
- **章节动态配置**：负责根据本次需求的真实特征，**最终决定** PRD 具体启用哪些章节、不启用哪些章节、哪些章节需要外拆。

需求类型识别只做"初始推荐"，不直接强制决定最终章节。

### 决策优先级

最终章节是否启用，必须根据以下优先级判断（发生冲突时，优先级高的覆盖优先级低的）：

| 优先级 | 决策来源 | 说明 |
|--------|----------|------|
| 1（最高） | 用户明确要求 | 用户直接说"这个需要"或"这个不需要" |
| 2 | 需求事实特征 | 需求本身是否涉及 AI、页面、状态流转、权限等 |
| 3 | 需求类型识别结果 | 10 种需求类型的初始推荐 |
| 4 | 预设方案默认章节 | 对应 Preset 推荐的章节组合 |
| 5（最低） | AI 自行判断 | 当以上都不明确时，AI 基于合理假设判断 |

### 冲突处理规则

1. **用户明确要求优先**：用户说启用就启用，说不用就不用。
2. **需求事实特征优先于类型识别**：识别为 AI 功能，不代表必须生成所有 AI 章节。如用户说"不需要评测体系"，则不生成 C8。
3. **非 AI 需求不得强行生成 AI 专属章节**：即使预设方案推荐了 AI 章节，非 AI 需求也不生成。
4. **预设方案章节只是候选，不是强制**：最终以本次需求的事实特征和用户明确要求为准。
5. **更具体的特征优先于更宽泛的类型**：需求事实特征（如"涉及状态流转"）优先于类型标签（如"大功能"）。

### 示例

| 场景 | 类型识别 | 事实特征 | 用户要求 | 最终决定 |
|------|----------|----------|----------|----------|
| 识别为 AI 功能，但 Prompt 很简单 | AI 功能需求 | Prompt 仅 1 个 | 无 | C4 不启用（无需版本管理） |
| 识别为小迭代，但涉及复杂状态 | 小迭代 | 涉及订单状态流转 | 无 | B3 启用（事实特征优先） |
| 识别为非 AI，用户坚持要 AI 章节 | 非 AI 功能 | 无 AI 特征 | "要加 AI 章节" | 按用户要求 + 提醒可能不必要 |
| 非 AI 需求 | 非 AI 功能 | 无 AI 特征 | 无 | 所有 C 类不生成 |

## 章节分类

PRD 章节库分为三类：

| 分类 | 说明 | 章节数 |
|------|------|--------|
| A. 通用基础章节 | 大多数需求都启用，小迭代可合并简化 | 9 |
| B. 条件启用章节 | 仅在特定条件下启用 | 6 |
| C. AI 专属章节 | 仅 AI 功能需求启用 | 10 |

## B. 条件启用章节

### B1. 业务流程图

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及多步骤操作、多角色协作、多端协作、复杂任务流程 |
| 不启用条件 | 单页面操作、简单功能、小迭代 |
| 不启用时说明 | "本需求为简单功能/小迭代，流程简单，不单独生成流程图" |
| 外拆概率 | 高（复杂流程外拆） |

### B2. 系统流程图

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及前后端交互、异步任务、第三方服务、复杂处理链路、多系统数据流转 |
| 不启用条件 | 纯前端功能、简单 CRUD |
| 不启用时说明 | "本需求不涉及多系统交互，无需系统流程图" |
| 外拆概率 | 高 |

### B3. 状态流转

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及订单、审核、任务、支付、退款、工单等有状态的对象；对象有多个状态且状态间有流转规则 |
| 不启用条件 | 无状态对象、单一状态 |
| 不启用时说明 | "本需求不涉及状态流转" |
| 外拆概率 | 高（多状态流转外拆） |

### B4. 权限设计

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及多角色、多身份、多端口权限、数据权限、操作权限 |
| 不启用条件 | 单角色、无权限差异 |
| 不启用时说明 | "本需求不涉及多角色权限" |
| 外拆概率 | 中（多角色复杂权限外拆） |

### B5. 埋点设计

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及数据统计、转化分析、运营分析、效果追踪、用户行为分析 |
| 不启用条件 | 无数据统计需求 |
| 不启用时说明 | "本需求无需数据埋点" |
| 外拆概率 | 中（埋点超过 10 个外拆） |

### B6. 风险与依赖

| 启用规则 | 内容 |
|----------|------|
| 启用条件 | 涉及第三方服务、政策合规、资源限制、算法不确定性、数据质量、排期风险 |
| 不启用条件 | 无特殊风险 |

| 外拆概率 | 低 |

## 章节启用决策流程

```
需求类型识别完成
    ↓
遍历全部章节（A 通用基础 + B 条件启用 + C AI 专属）
    ↓
每个章节判断：
  ├── 通用基础章节 → 默认启用，小迭代简化
  ├── 条件启用章节 → 检查是否满足启用条件
  └── AI 专属章节 → 仅 AI 需求时检查
    ↓
输出章节启用规划表
    ↓
在 00_交付物与章节规划.md 中记录
```
