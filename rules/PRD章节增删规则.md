# PRD 章节增删规则

## 核心原则

PRD 章节库是活的，可以新增、停用、调整。但所有变更必须有记录、有原因、可追溯。

---

## 新增章节

### 新增流程

当需要新增一个 PRD 章节时，只需做三件事：

#### 1. 新增章节模板

在 `templates/sections/` 下按分类创建模板文件：

```
templates/sections/
├── 通用/           ← 通用基础章节模板
├── 条件启用/       ← 条件启用章节模板
└── AI专属/         ← AI 专属章节模板
```

**命名格式**：`章节ID_章节名称.md`

**模板格式**：

```markdown
# 章节模板：[章节名称]

## 章节目标
[这一章要完成什么]

## 适用条件
[什么需求类型下启用]

## 必须输出
[必须包含的内容列表]

## 模板内容

### [小节1]
[模板结构和填写说明]

### [小节2]
[模板结构和填写说明]

---

> 使用方式：按以上结构逐项填写。方括号 `[]` 内的内容为填写说明，填写后删除。
```

#### 2. 新增方法论（可选）

在 `knowledge/` 下新增对应的方法论文档。

如果没有现成方法论，可以先留空，标注 `待补充`。

#### 3. 在章节注册表中登记

在 `rules/PRD章节注册表.md` 中按以下格式登记：

```markdown
## 章节：[章节名称]

| 字段 | 内容 |
|------|------|
| 章节 ID | [唯一英文 ID] |
| 章节名称 | [中文名称] |
| 章节分类 | 通用基础 / 条件启用 / AI 专属 |
| 默认启用 | 是 / 否 |
| 启用条件 | [什么情况下启用] |
| 禁用条件 | [什么情况下不启用] |
| 适用需求类型 | [列表] |
| 生成前读取 | [方法论文件路径、模板文件路径] |
| 必须输出 | [必须包含的内容] |
| 是否可外拆 | 是 / 否 |
| 外拆条件 | [条件下外拆] |
| 主 PRD 保留 | [如果外拆，主文档保留什么] |
| 专项文档命名 | [如果外拆，文件名] |
| 登记日期 | YYYY-MM-DD |
| 版本 | v1.0 |
```

## 删除/停用章节

### 不能直接物理删除

删除章节不能直接删除注册表中的记录，否则历史项目的引用会失效。

### 停用流程

1. 在 `rules/PRD章节注册表.md` 中，将该章节的**默认启用**改为 `否`，并在章节登记信息中增加：

```markdown
| 停用状态 | 已停用 |
| 停用日期 | YYYY-MM-DD |
| 停用原因 | [详细说明为什么要停用这个章节] |
| 替代章节 | [如果有替代章节，写章节 ID；如果没有，写"无"] |
```

2. 保留 `templates/sections/` 下的章节模板文件，不要删除。

3. 在 `rules/PRD章节增删规则.md` 的变更记录中登记（见下方）。

---

## 调整章节

### 调整流程

当需要调整章节（如修改启用条件、修改内容要求、修改分类）时：

1. 在 `rules/PRD章节注册表.md` 中更新该章节的登记信息

2. 增加版本记录：

```markdown
| 版本 | v1.0 → v1.1 |
| 最近修改日期 | YYYY-MM-DD |
| 修改内容 | [具体修改了什么] |
| 修改原因 | [为什么要改] |
```

3. 同步更新 `templates/sections/` 下的对应模板

4. 在变更记录中登记

## 变更记录

### 变更记录表

每次新增、停用、调整章节时，在此记录：

```markdown
| 日期 | 操作 | 章节 ID | 章节名称 | 说明 |
|------|------|---------|----------|------|
| YYYY-MM-DD | 新增 | ... | ... | ... |
| YYYY-MM-DD | 停用 | ... | ... | ... |
| YYYY-MM-DD | 调整 | ... | ... | v1.0→v1.1: 修改了... |
```

## 版本兼容原则

1. **旧版本 PRD 不受影响**：已生成的 PRD 文档不因章节库变更而需要修改。
2. **章节 ID 不重复使用**：已停用的章节 ID 不再分配给新章节。
3. **模板文件不删除**：停用章节的模板保留在 `templates/sections/` 中，供历史参考。
4. **注册表保留停用记录**：停用的章节仍在注册表中，但标注为停用。
