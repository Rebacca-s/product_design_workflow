# A6 页面与交互说明 — 章节模板

> **默认生成项**：涉及页面（Web、后台、小程序、App）的需求，A6 必须按此模板输出。页面结构图不是可选项，是默认生成项。
>
> 每个页面独立输出一套完整的 5 节结构。多个页面时，每个页面都按相同结构重复。

---

## 使用说明

1. 每个页面按 5 个固定小节输出
2. ASCII 结构图必须画，让研发不需要脑补页面布局
3. 元素说明表覆盖全页面所有交互元素
4. 交互说明覆盖所有操作行为
5. 状态说明覆盖至少 7 种页面状态

---

## 第 2 节：页面结构草图（ASCII Wireframe）

**必须使用代码块绘制，至少包含页面布局骨架。**

### 绘制规范

1. 使用 `┌ ┐ └ ┘ ├ ┤ ─ │ ┬ ┴ ┼` 等制表符
2. 标注关键区域名称（如"搜索区""列表区""分页区"）
3. 标注关键按钮位置和文案
4. 不需要高保真，只需让研发一眼理解页面结构
5. 如果页面有弹窗（Dialog/Drawer），单独画弹窗结构图

## 第 3 节：页面元素说明

使用表格描述页面所有元素，至少覆盖以下类型。

### 元素类型速查表

| 元素类型 | 说明 | 何时使用 |
|----------|------|----------|
| Input | 文本输入框 | 用户输入文字、数字、搜索关键词 |
| Select | 下拉选择器 | 从预定义选项中选择一个 |
| Radio | 单选框 | 从 2-5 个选项中选择一个 |
| Checkbox | 复选框 | 多选场景 |
| Button | 按钮 | 搜索、提交、保存、删除、导出等操作入口 |
| Table | 数据表格 | 列表数据展示 |
| Card | 卡片 | 信息展示、内容列表（移动端常用） |
| Tab | 标签页切换 | 同类内容的不同视图切换 |
| Dialog | 弹窗 | 确认操作、查看详情、表单输入（居中弹出） |
| Drawer | 抽屉 | 详情面板、筛选面板（侧边滑出） |
| Upload | 文件上传 | 图片、文件上传 |
| Tree | 树形控件 | 组织架构、分类层级 |
| Pagination | 分页器 | 数据量大时分页展示 |

### 元素说明表格式

```markdown
### 页面元素说明

| 区域 | 元素 | 组件类型 | 是否必填/必显 | 默认值/占位文案 | 说明 |
|------|------|----------|--------------|----------------|------|
| 搜索区 | 用户搜索框 | Input | 否 | placeholder: "搜索用户昵称/手机号" | 支持模糊搜索，输入后回车或点击搜索按钮触发 |
| 搜索区 | 等级筛选 | Select | 否 | 默认"全部" | 下拉选项：全部/Lv1/Lv2/Lv3 |
| 搜索区 | 日期范围 | DatePicker | 否 | 默认近 30 天 | 筛选加入时间范围 |
| 搜索区 | 搜索按钮 | Button | 是 | 文案"搜索" | 点击后按条件刷新列表 |
| 搜索区 | 重置按钮 | Button | 是 | 文案"重置" | 点击后清空所有筛选条件并刷新 |
| 列表区 | 数据表格 | Table | 是 | — | 展示分销记录列表 |
| 列表区 | 头像列 | Image(Table) | 是 | 默认头像 | 展示用户微信头像 |
| 列表区 | 昵称列 | Text(Table) | 是 | — | 展示用户微信昵称，点击跳转用户详情 |
| 列表区 | 等级列 | Tag(Table) | 是 | — | Lv1 灰色/Lv2 蓝色/Lv3 金色 |
| 列表区 | 团队人数列 | Text(Table) | 是 | — | 展示当前下级人数 |
| 列表区 | 操作-详情 | Button(Table) | 是 | 文案"详情" | 点击打开用户详情弹窗 |
| 分页区 | 分页器 | Pagination | 是（超过 1 页时） | 默认第 1 页，每页 20 条 | 显示总数、页码、上一页/下一页 |
| 弹窗 | 用户详情弹窗 | Dialog | 条件触发 | — | 点击"详情"按钮后弹出 |
```

## 第 4 节：页面交互说明

描述页面所有交互行为。每种交互至少说明：触发条件 → 行为 → 反馈。

```markdown
### 页面交互说明

#### 点击交互

| 操作 | 触发元素 | 触发条件 | 行为 | 反馈 |
|------|----------|----------|------|------|
| 搜索 | 搜索按钮 | 输入框不为空 | 按条件刷新列表 | 列表刷新 + Loading |
| 重置 | 重置按钮 | 始终可点击 | 清空所有筛选条件，恢复默认 | 列表刷新 |
| 查看详情 | 表格"详情"按钮 | 始终可点击 | 打开用户详情弹窗 | 弹窗弹出 |
| 关闭详情 | 弹窗"关闭"按钮 / ✕ | 弹窗已打开 | 关闭弹窗 | 弹窗消失 |
| 切换页码 | 分页器页码 | 始终可点击 | 切换到对应页 | 列表刷新 + 滚动到顶部 |
| 导出 | 导出按钮 | 有数据时可用 | 导出当前筛选结果为 Excel | Loading + 下载文件 |
| 删除 | 表格"删除"按钮 | 有权限时可用 | 弹出二次确认 | 确认后删除 + Toast |

#### 跳转交互

| 操作 | 触发元素 | 目标页面 | 携带参数 |
|------|----------|----------|----------|
| 进入页面 | 侧边栏菜单"分销记录" | 当前页面 | 无 |
| 查看用户详情 | 列表昵称列 | 用户详情页 | 用户 ID |

#### 弹窗交互

| 弹窗名称 | 触发方式 | 关闭方式 | 尺寸 |
|----------|----------|----------|------|
| 用户详情弹窗 | 点击"详情"按钮 | 点击关闭/✕/遮罩层 | 600px 宽（后台）/ 全屏（移动端） |

#### 校验交互

| 校验场景 | 校验规则 | 触发时机 | 失败提示 |
|----------|----------|----------|----------|
| 搜索关键词 | 不超过 50 个字符 | 输入时 | "搜索关键词不超过 50 个字符" |
| 日期范围 | 开始日期 ≤ 结束日期 | 选择后 | "开始日期不能晚于结束日期" |

#### 即时反馈

| 操作 | 反馈方式 | 反馈内容 |
|------|----------|----------|
| 搜索中 | Loading + 骨架屏 | 列表区域显示骨架屏 |
| 搜索完成 | 列表刷新 | 展示搜索结果 |
| 搜索无结果 | 空状态 | "未找到匹配的分销记录" |
| 删除成功 | Toast | "删除成功" |
| 导出成功 | Toast + 下载 | "导出成功，文件已开始下载" |
| 接口异常 | Toast | "网络异常，请稍后重试" |
```

## 第 5 节：页面状态说明

每个页面至少说明以下 7 种状态。

```markdown
### 页面状态说明

| 状态 | 触发条件 | 页面展示 | 用户可操作 |
|------|----------|----------|-----------|
| **首次进入** | 用户首次进入页面 | 搜索区默认值 + 列表加载默认数据 | 搜索、筛选、翻页 |
| **正常状态** | 数据加载完成，有数据 | 完整页面结构，列表有数据 | 所有操作 |
| **Loading** | 数据正在加载中 | 列表区显示骨架屏（3 行灰色占位卡片）；搜索按钮显示 loading 态 | 无（等待加载完成） |
| **查询结果为空** | 搜索/筛选后无匹配数据 | 列表区显示空状态插画 + "未找到匹配的分销记录" + "试试修改筛选条件" | 修改搜索条件、点击重置 |
| **首次使用（全局空状态）** | 从未产生任何分销记录 | 列表区显示空状态插画 + "还没有分销记录" + "去邀请用户加入分销" | 点击引导按钮跳转邀请页 |
| **无权限** | 当前角色无权访问 | 居中显示锁图标 + "您没有权限访问此页面" + "请联系管理员" | 返回上一页 |
| **异常状态** | 接口超时/网络异常 | 列表区显示错误图标 + "数据加载失败" + [重试] 按钮 | 点击重试 |
| **操作成功** | 删除/导出等操作成功 | 页面不变 + Toast 提示 | 继续操作 |
```

## 检查清单

每个页面输出完成后，自查：

- [ ] 页面概览：名称、路径、作用、入口、角色、接入方式 6 个维度齐全
- [ ] 结构草图：有 ASCII Wireframe，布局清晰，区域标注明确
- [ ] 结构草图：如果有弹窗/Drawer，单独画了弹窗结构
- [ ] 元素说明表：覆盖了页面所有交互元素（至少 Input/Select/Button/Table/Pagination）
- [ ] 元素说明表：每个元素有区域、类型、必填/必显、默认值、说明
- [ ] 交互说明：覆盖点击、跳转、弹窗、校验、即时反馈
- [ ] 状态说明：覆盖首次进入、Loading、正常、空状态、无权限、异常、成功 7 种状态
