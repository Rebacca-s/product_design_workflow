## 3. 核心页面详细设计说明

### P1. 门店列表（小程序）

#### 页面目标
用户快速找到附近合适的门店，了解门店类型、距离、评分后做出选择。

#### 页面结构
```
┌─────────────────────────────┐
│  🔍 搜索门店              📍 │ ← 搜索栏 + 定位按钮
├─────────────────────────────┤
│ [全部] [自营] [合作医院] [体检] │ ← 类型筛选标签（横向滚动）
│ 📋 列表视图 │ 🗺️ 地图视图      │ ← 视图切换
├─────────────────────────────┤
│ ┌───────────────────────┐   │
│ │ 🏥 [图]  多爱宠自营(朝阳)  │   │ ← 门店卡片
│ │           ★4.8(128条)    │   │
│ │           📍朝阳路XX号 1.2km│   │
│ │           [商品自提][体检预约]│   │
│ │                    营业中🟢│   │
│ └───────────────────────┘   │
│ ┌───────────────────────┐   │
│ │ 🏥 [图]  合作宠物医院(海淀) │   │
│ │           ★4.5(86条)     │   │
│ │           📍海淀路XX号 3.5km│   │
│ │           [体检预约]       │   │
│ │                    营业中🟢│   │
│ └───────────────────────┘   │
│           ... 更多门店        │
└─────────────────────────────┘
```

#### 信息层级
1. **一级信息（首屏可见）**：门店名称、评分、距离、类型标签、营业状态
2. **二级信息（滚动可见）**：更多门店卡片
3. **三级信息（点击进入）**：门店完整详情

#### 状态设计

**默认状态**：门店卡片列表，有定位时按距离排序。

**空状态**：
- 插图：地图搜索图标
- 文案："暂无门店"
- 引导操作：无（等待平台配置门店）

**加载状态**：骨架屏（卡片占位）

**定位未授权**：
- 顶部提示条："开启定位后可按距离查看附近门店  [去开启]"
- 门店列表按评分排序

**网络错误**：
- 插图：网络断开图标
- 文案："网络连接失败"
- 按钮："重试"

#### 交互说明
- 下拉刷新：重新加载门店列表
- 滚动到底：加载更多
- 点击卡片：进入门店详情（右滑推入）
- 点击类型标签：切换筛选，刷新列表
- 点击联系电话：弹出拨打确认弹窗

#### 状态设计

**默认状态**：完整展示所有区块。

**门店暂停预约**：预约时间区和体检预约区隐藏，顶部展示"该门店暂停预约"提示条。

**门店休息中**：营业时间旁显示"休息中"标签，商品/服务正常展示。

**门店已关闭**：顶部展示"该门店已停止服务"，商品和服务区全部隐藏。

**加载状态**：骨架屏。

**网络错误**：错误提示 + 重试按钮。

#### 交互说明
- 头图左右滑动切换
- 点击地址调起地图APP导航
- 点击电话弹出拨打确认
- 日期横向滑动选择，切换时段
- 点击时段弹出确认
- 点击商品卡片进入商品详情
- 点击体检"预约"进入体检详情
- 点击"全部评价"进入评价列表

### P6. 订单详情-门店自提订单（小程序）

#### 订单列表 Tab 整合

**商品订单 Tab**：待付款 | **待发货/待使用** | 待收货 | 待评价 | 已完成 | 退款/售后

- "待发货/待使用"Tab 同时展示快递配送订单（待发货）+ 门店自提订单（待使用）
- 每个订单卡片展示各自的真实状态标签

**体检订单 Tab**：待付款 | **待寄出取样器/待使用** | 待寄出样本 | 检验中 | 待评价 | 已完成 | 退款/售后

- "待寄出取样器/待使用"Tab 同时展示寄样订单（待寄出取样器）+ 到店订单（待使用）
- 已过期订单不单独建Tab，展示在"已完成"Tab中，卡片标签为"已过期"

#### 页面目标
用户查看订单状态、核销码、门店信息，到店出示核销码完成核销。

#### 页面结构
```
┌─────────────────────────────┐

├─────────────────────────────┤
│        订单状态：待使用        │ ← 醒目标识

├─────────────────────────────┤
│ ┌───────────────────────┐   │
│ │                       │   │
│ │    [ 核销二维码 ]      │   │ ← 二维码（大尺寸、白色背景）
│ │                       │   │
│ └───────────────────────┘   │
│   数字核销码：8361 2947  📋  │ ← 大字体数字码 + 复制按钮
```

#### 状态设计

**待使用状态**：展示核销码，状态标识为蓝色。

**已核销状态**：隐藏核销码区，状态标识为绿色。展示"已核销于 2026-07-03 14:30"。

**已完成状态**：隐藏核销码区，状态标识为灰色。底部出现"评价门店"按钮。

**已取消/已退款**：隐藏核销码区，状态标识为灰色。

#### 交互说明
- 点击二维码 → 全屏放大展示（黑底白码）
- 点击数字码复制按钮 → 复制到剪贴板 + Toast"已复制"
- 点击门店电话 → 拨打确认
- 点击门店地址 → 调起地图导航
- 核销已在门店后台完成 → 小程序需展示最新状态（下拉刷新或自动轮询）

## 4. 复用组件清单

| 组件名称 | 使用场景 | 说明 |
|----------|----------|------|
| 门店卡片 | 门店列表、门店选择器 | 统一的门店信息卡片组件 |

| 门店状态标签 | 门店列表、门店详情、门店选择器 | 营业中/休息中/暂停预约 |

## 5. 设计风格建议

- **整体风格**：简洁温暖，符合宠物行业调性
- **主色调**：延续多爱宠现有品牌色
- **门店类型标签**：自营(橙色)、合作医院(蓝色)、体检医院(绿色)
- **状态色彩**：待使用(蓝色)、已核销(绿色)、已取消(灰色)、暂停(黄色)
- **图标风格**：线性图标为主，重点操作可用面性图标
