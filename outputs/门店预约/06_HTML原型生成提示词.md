# HTML 原型生成提示词 — 多爱宠门店预约

---

## 产品背景

多爱宠是一个宠物服务平台小程序，用户可在上面购买宠物商品和宠物体检服务。本期新增"门店预约"能力，让用户可以在购买商品时选择"门店自提"，在购买体检时选择"线下门店预约"，并通过门店列表发现附近门店。

## 页面范围

本次需生成以下页面的 HTML 原型：

### 小程序C端（移动端 375px 宽度优先）

1. **门店列表页** — 展示附近门店，支持类型筛选
2. **门店详情页** — 展示门店完整信息、可售商品、可预约服务、评价
3. **商品详情页（改造部分）** — 新增履约方式切换（寄货/门店自提）
4. **订单确认页（门店自提版）** — 展示门店信息替代收货地址
5. **订单详情页（门店自提版）** — 展示核销码（二维码+数字码）+ 门店信息
6. **订单详情页（体检预约版）** — 展示核销码 + 预约时间 + 改期/取消按钮
7. **预约改期选择器** — 底部弹出的日期+时段选择器
8. **取消确认弹窗** — 取消预约的二次确认弹窗

### PC后台（PC端 1440px 宽度优先）

6. **门店后台-工作台** — 核销入口 + 今日概览
7. **核销确认弹窗** — 确认订单信息后核销

## 设计风格要求

- **整体风格**：简洁温暖，宠物行业调性，白色背景为主，卡片式布局
- **移动端**：375px 宽度，模拟小程序界面（顶部导航栏29px + 内容区）
- **PC后台**：标准后台布局，左侧深色导航 + 右侧白色内容区
- **色彩**：
  - 主色：橙色系（#FF6B35，宠物行业温暖感）
  - 辅助色：蓝色（#4A90D9，合作医院标签）、绿色（#52C41A，体检医院标签/营业中）
  - 状态色：蓝色(待使用)、绿色(已核销)、灰色(已完成/已取消)、黄色(暂停)
- **圆角**：卡片12px，按钮8px，标签4px
- **阴影**：卡片使用轻阴影（box-shadow: 0 2px 8px rgba(0,0,0,0.08)）
- **字体**：系统默认中文字体，标题16-18px，正文14px，辅助文字12px
- **图标**：使用 emoji 或简单 SVG 图标代替

## 交互要求

- 所有按钮有 hover/active 态
- 标签切换有过渡动画
- 弹窗从底部滑入（移动端），模态居中（PC端）
- 骨架屏加载效果（简单实现即可）
- 二维码区域在移动端可点击全屏放大
- 使用真实的中文内容（门店名、地址、评价等）

## 各页面具体要求

### 1. 门店列表页（移动端）

- 顶部：搜索栏 + 定位图标
- 筛选标签行：全部 | 自营门店 | 合作医院 | 体检医院（点击切换高亮）
- 视图切换：列表/地图两个小按钮
- 门店卡片列表：
  - 左侧缩略图（100x100，灰色占位 + 图标）
  - 右侧：名称 + 类型标签(彩色小徽章)、星级评分 + 评价数、地址 + 距离(如 1.2km)、服务标签行(商品自提/体检预约)、营业状态
- 底部加载更多
- 需展示至少 4 个门店卡片，类型和评分各不相同

### 2. 门店详情页（移动端）

- 顶部头图轮播（3张占位图，可左右滑动指示器）
- 门店基础信息区：名称、类型标签、评分+评价数、地址、电话、营业时间
- 服务标签行
- 可预约时间区（日期横向滑动7天 + 时段网格），部分时段标记"已约满"
- 可自提商品区：横向滚动商品卡片（商品图+名称+价格）
- 可预约体检区：体检服务卡片列表（名称+简介+价格+预约按钮）
- 评价区：评分概览 + 2-3条精选评价（用户头像+昵称+星级+文字+图片+时间）
- 到店须知区：文本列表

### 3. 商品详情页（移动端，仅改造部分）

- 在价格下方、购买按钮上方插入履约方式选择
- 两个并排选项卡片："🚚 寄货" 和 "🏪 门店自提"（点击切换高亮）
- 选择"门店自提"后下方出现：已选门店信息行 + "更换 >"按钮
- 未选门店时显示："请选择自提门店 >" （点击可弹出底部门店选择器模拟）

### 4. 订单确认页-门店自提版（移动端）

- 顶部：履约方式标签"门店自提"
- 门店信息卡片：名称、地址、电话、距离
- 提货说明："预计下单后2小时可到店自提，请携带核销码"
- 商品信息：商品图+名称+数量+价格
- 价格明细：商品金额、优惠、合计
- 底部固定：合计金额 + "提交订单"按钮

### 5. 订单详情页-门店自提版（移动端）

- 订单状态横幅："待使用" + "请到店出示核销码完成取货"
- 核销码区域（核心区域）：
  - 白色背景大卡片
  - 中央：二维码占位图（200x200，带边框）
  - 下方：大字体数字码"8361 2947" + 复制按钮
  - 提示："点击二维码可全屏放大"
- 门店信息卡片
- 商品信息行
- 订单信息行（编号、时间、支付方式、金额）
- 提货说明
- 底部："评价门店"按钮（仅在已核销/已完成状态展示）

### 6. 订单详情页-体检预约版（移动端）

- 订单状态横幅："待使用" + "请按时到店出示核销码"
- 核销码区域（与门店自提版相同）
- 预约门店信息卡片：名称、地址、电话
- **预约时间区**：
  - 当前预约时间："2026-07-03 09:00-09:30"（大字体）
  - **改期** 按钮（蓝色边框按钮）和 **取消预约** 按钮（红色边框按钮）并列
- 体检项目信息
- 订单信息行
- 到店须知
- **注意**：改期和取消按钮仅在"待使用"状态展示

### 7. 预约改期选择器（移动端）

- 底部弹出的半屏弹窗
- 顶部：返回箭头 + "选择新时间" + "完成"按钮
- 当前预约信息："当前预约：7/3 09:00-09:30 ↓ 改至"
- 日期选择行：横向滚动，7天日期（今日+未来6天）
- 时段网格：
  - 2列网格
  - 可预约时段：蓝色文字
  - 已约满时段：灰色置灰"已约满"
- 底部提示："改期将释放原时段名额"
- 选择新时段后高亮选中

### 8. 取消确认弹窗（移动端）

- 底部弹出的模态弹窗
- 标题："确认取消预约"
- 内容区：
  - "取消后将释放该时段预约名额"
  - 原预约信息："2026-07-03 09:00-09:30 多爱宠自营(朝阳店)"
  - 取消原因（选填）：标签行 ["门店太远"] ["时间冲突"] ["其他"]
  - 文本输入框（可选）
- 底部：红色"确认取消"主按钮 + "返回"次按钮

### 9. 门店后台-工作台（PC端）

- 左侧深色导航栏（工作台/体检预约/商品自提/门店设置/上下架/评价）
- 顶部：门店名称 + "工作台"
- 4个概览卡片：总待核销、今日待核销(数字大且醒目)、今日已核销、今日预约
- 核销操作区（居中醒目）：
  - 大卡片内
  - "扫码核销"大按钮 + 摄像头图标
  - 分割线 + "或"
  - 手动输入框 + "确认核销"按钮
- 今日预约到店列表：表格展示（用户昵称、项目、预约时间、状态标签、操作按钮）

### 10. 核销确认弹窗（PC端）

- 模态弹窗（居中，500px宽）
- 标题："核销确认"
- 信息行：用户头像、用户昵称、手机号后4位、订单类型、商品/服务名称、预约时间、支付状态
- 底部："确认核销"主按钮 + "取消"次按钮
- 点击确认后弹窗关闭，模拟Toast提示"核销成功"

### 11. 我的预约页（移动端）

- 顶部Tab：全部/待付款/待使用/检验中/待评价/已完成/已取消
- 订单卡片：类型标签（🏪商品自提/🏥体检预约）、门店名称、预约时间、地址、状态标签、金额
- 待使用订单：底部[修改时间] [取消预约]按钮
- 待付款订单：底部[去支付]按钮

### 12. 购物车页（移动端）

- 顶部导航："购物车" + 右侧"编辑"按钮
- 全选栏："☐ 全选 (共N件)"
- 商品按履约方式分组展示：
  - 🚚 线上寄货组（蓝色标签）：寄货商品可合并，不限门店来源
  - 🏪 门店自提·{门店名}组（橙色标签）：同一门店商品合并，不同门店独立分组
- 每组内商品行：勾选框+商品缩略图(80x80)+名称+单价+数量加减器+小计
- 自提商品行底部有"更换门店 >"链接
- 失效商品：置灰+"已失效"标签，不可勾选
- 底部固定栏：
  - 合计金额
  - 拆单提示："📋 将生成 N 笔订单" + 每笔分组和金额
  - [结算(N笔)] 主按钮
- 编辑态：每行出现⭕删除图标+"删除选中"+"清空失效"+"完成"
- 空状态：插画+"购物车空空如也"+"去逛逛 →"
- ⚠️ 注意：体检服务不出现在购物车，仅支持"立即预约"

### 13. 评价表单页（移动端）

- 顶部：关联门店名称+订单信息（系统自动，不可编辑）
- 综合评分：5星点击选择，必填
- 评价内容：多行文本输入，最少10字最多500字，实时字数统计
- 图片上传：最多9张，支持相册/拍照，可预览和删除
- 底部：[提交评价]按钮，未评分或内容不足10字时置灰

### 14. 评价列表页（移动端）

- 顶部评分概览：平均星级+总评价数+评分分布条（5星~1星）
- 评价列表：用户头像+昵称+星级+文字内容+图片(可点击放大)+订单类型标签+时间
- 分页加载+下拉刷新

### 15. 门店后台登录页（PC端）

- 居中登录卡片：Logo+"多爱宠门店后台"标题
- 手机号输入框+密码输入框
- [登录]主按钮
- 底部提示："忘记密码？请联系平台运营重置"

## 输出格式

- 单个 HTML 文件，包含所有页面
- 使用标签切换来切换不同页面视图（顶部标签栏：门店列表 | 门店详情 | 商品详情 | 订单确认 | 订单详情-自提 | 订单详情-体检 | 改期选择器 | 取消弹窗 | 后台工作台）
- 移动端页面使用 375px 容器居中展示（模拟手机屏幕）
- PC端页面使用全宽布局
- 使用原生 HTML + CSS + 少量 JS 实现
- 不需要引入外部依赖
- 所有文字使用中文
