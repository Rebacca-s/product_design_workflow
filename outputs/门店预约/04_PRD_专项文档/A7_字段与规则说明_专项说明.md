## 四-B、预约时间粒度配置（平台级）

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| slot_duration | int | 是 | 预约时段粒度（分钟） | 30 |
| configurable_by | enum | 是 | 配置权限 | "platform"=仅平台可配 |

**规则**：
- 预约时段粒度由平台总后台统一配置，门店不可修改
- 可选粒度：15分钟 / 30分钟 / 60分钟
- 修改粒度后，已生成的未来时段需重新生成
- 粒度变更不影响已有订单

## 五、订单扩展字段

以下为现有订单表需新增的字段：

| 字段名 | 类型 | 必填 | 说明 | 适用订单类型 |
|--------|------|------|------|-------------|
| fulfillment_type | enum | 是 | 履约方式 | 全部 |
| store_id | string | 否 | 关联门店ID | 门店自提/线下预约 |
| appointment_date | date | 否 | 预约日期 | 线下预约 |
| appointment_slot | string | 否 | 预约时段 | 线下预约 |
| slot_id | string | 否 | 预约时段ID | 线下预约 |
| verify_code | string | 否 | 数字核销码 | 门店自提/线下预约 |
| verify_qr_url | string | 否 | 核销二维码URL | 门店自提/线下预约 |
| verified_at | datetime | 否 | 核销时间 | 门店自提/线下预约 |
| verified_by | string | 否 | 核销人（门店人员ID） | 门店自提/线下预约 |

**履约方式枚举**：
- `delivery` — 线上寄货（商品快递配送）
- `pickup` — 门店自提（商品到店自取）
- `sample_delivery` — 线上寄样体检
- `store_appointment` — 线下门店预约（体检到店）

**订单状态枚举（商品）**：
- `pending_payment` — 待付款
- `pending_ship` — 待发货（仅快递）
- `pending_use` — 待使用（仅门店自提，替代待发货→待收货段）
- `shipped` — 待收货（仅快递）
- `pending_review` — 待评价
- `completed` — 已完成

**订单状态枚举（体检）**：
- `pending_payment` — 待付款
- `pending_sampler` — 待寄出取样器（仅寄样）
- `pending_use` — 待使用（仅门店预约）
- `pending_sample` — 待寄出样本（仅寄样）
- `testing` — 检验中
- `pending_review` — 待评价
- `completed` — 已完成

## 七、门店评价

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| review_id | string | 是 | 评价唯一ID | — |
| store_id | string | 是 | 被评价门店ID | — |
| user_id | string | 是 | 评价用户ID | — |
| order_id | string | 是 | 关联订单ID | — |
| order_type | enum | 是 | 订单类型 | pickup=商品自提 / appointment=体检预约 |
| rating | int | 是 | 综合评分 | 1-5星 |
| content | string | 是 | 评价内容 | 最少10字符，最长500字符 |
| images | array[string] | 否 | 评价图片 | 最多9张 |
| is_hidden | boolean | 是 | 是否被运营隐藏 | 默认false |
| created_at | datetime | 是 | 评价时间 | — |

**门店综合评分计算**：
- 门店综合评分 = 所有未隐藏评价的 rating 算术平均分
- 计算公式：`AVG(rating) WHERE is_hidden = false AND store_id = X`
- 结果保留 1 位小数（如 4.8）
- 评价隐藏/取消隐藏后实时重算
- 无评价时展示"暂无评分"

## 九、交互规则汇总

| 规则编号 | 规则 | 触发条件 | 适用范围 |
|----------|------|----------|----------|
| R1 | 履约方式切换清空之前选择 | 用户在详情页切换履约方式 | 小程序 |
| R2 | 仅展示平台已配置且门店未下架的商品/服务 | 门店选择器/门店详情展示 | 小程序 |
| R3 | 仅营业中门店可选 | 门店选择器过滤 | 小程序 |
| R4 | 预约时段粒度由平台统一配置（15/30/60分钟），门店不可修改 | 预约时间选择 | 小程序 |
| R5 | 核销码仅"待使用"状态展示 | 订单详情判断状态 | 小程序 |
| R6 | 仅本门店订单可核销 | 门店后台核销校验 | 门店后台 |
| R7 | 仅待使用状态订单可核销 | 核销前校验 | 门店后台 |
| R8 | 核销不可逆 | 核销后状态变更 | 全局 |
| R9 | 平台配置变更即时生效，不影响已有订单 | 平台后台 | 全局 |
| R10 | 门店下架操作即时生效，不影响已有订单 | 门店后台 | 全局 |
| R11 | 门店列表排序 = 距离排序 + 排序权重干预；权重越高越靠前 | 门店列表加载 | 小程序 |
