## 一、商品订单状态

### 快递配送

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待发货 | pending_ship | 已支付，等待发货 | 支付成功 | 申请退款 |
| 待收货 | shipped | 已发货，等待收货 | 商家发货 | 确认收货、申请退款 |
| 待评价 | pending_review | 已收货，等待评价 | 用户确认收货 | 评价、申请售后 |
| 已完成 | completed | 订单完结 | 超过自动确认收货时间 / 用户评价 | 再次购买 |

### 门店自提

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付（名额已占用） | 用户点击"立即购买"选择门店自提 | 支付、取消 |
| 待使用 | pending_use | 已支付，等待到店核销 | 支付成功 | 查看核销码、修改时间、取消预约 |
| 待评价 | pending_review | 门店核销完成，等待评价 | 门店核销 | 评价 |
| 已完成 | completed | 订单完结 | 用户评价 / 超时自动完成 | 再次购买 |

## 二、体检订单状态

## 四、状态流转图

### 商品订单

```
快递配送：
待付款 ──支付成功──→ 待发货 ──商家发货──→ 待收货 ──确认收货──→ 待评价 ──评价──→ 已完成

门店自提：
待付款 ──支付成功──→ 待使用 ──门店核销──→ 待评价 ──评价──→ 已完成
    │                  │
    └──支付超时/取消──→ 已取消      ├──修改时间──→ 待使用（更新预约时间，原时段释放+新时段占用）
                       │
                       ├──取消预约──→ 已取消（自动触发退款，走退款流程）
                       │
                       └──过期未到店──→ 已过期（展示在"已完成"Tab，标签为"已过期"，不退款不释放名额）
```

### 体检订单

```
线上寄样：
待付款 ──支付成功──→ 待寄出取样器 ──商家寄出──→ 待寄出样本 ──商家收货──→ 检验中 ──完成──→ 待评价 ──评价──→ 已完成

线下门店预约：
待付款 ──支付成功──→ 待使用 ──门店核销──→ 检验中 ──完成──→ 待评价 ──评价──→ 已完成
    │                  │
    └──支付超时/取消──→ 已取消      ├──修改时间──→ 待使用（更新预约时间，原时段释放+新时段占用）
                       │
                       ├──取消预约──→ 已取消（自动触发退款，走退款流程）
                       │
                       └──过期未到店──→ 已过期（展示在"已完成"Tab，标签为"已过期"，不退款不释放名额）
```

### 禁止流转

| 禁止 | 原因 |
|------|------|
| 待使用 → 直接退款（不经取消） | 退款必须通过取消预约触发，不允许绕过取消直接退款 |
| 检验中/待评价/已完成/已过期 → 取消/退款 | 已履约或已过期，不可取消或退款 |
| 已过期 → 任何状态 | 终态 |
| 已取消 → 任何状态 | 终态（退款完成后进入已取消，不可再操作） |

## 六、已过期规则

| 规则项 | 说明 |
|--------|------|
| 触发 | 系统定时任务，每天营业结束后扫描当天"待使用"状态门店订单 |
| 状态 | "待使用" → "已过期"（终态） |
| 退款 | 不退款 |
| 名额 | 不释放 |
| 核销码 | 自动失效 |
| 前端展示 | 不单独建Tab，展示在"已完成"Tab中，卡片标签为"已过期" |

---

## 七、修改时间规则

| 规则项 | 说明 |
|--------|------|
| 修改次数 | **不限次数** |
| 修改时间范围 | 可选未来任意日期+时段 |
| 修改截止 | **预约时段开始前 2 小时**（如预约 14:00-14:30，则当天 12:00 前可修改） |
| 不可修改 | 检验中、待评价、已完成、已过期、已取消 |
| 名额 | 原时段释放 + 新时段占用（原子操作：先占新时段成功，再释放原时段） |
| 适用订单 | 商品自提订单（修改自提时间）+ 体检预约订单（修改预约时间） |

## 八、核销码状态

| 订单状态 | 核销码状态 | 核销时行为 |
|----------|-----------|-----------|
| 待使用 | 有效 | 可核销，核销后进入下一状态 |
| 待评价/检验中/已完成 | 无效 | 提示"该订单已完成" |
| 已过期 | 无效 | 提示"该订单已过期" |
| 已取消 | 无效 | 提示"该订单已取消" |

> **注意**：订单状态中不存在"已核销"这一独立状态。核销是一个**操作动作**，不是状态。门店核销后，商品自提订单直接进入"待评价"，体检到店订单进入"检验中"。核销码仅在"待使用"状态展示。

## 九、预约名额占用与释放规则

### 名额占用时机

> **关键规则**：用户点击"立即预约"即占用名额，而非支付成功后才占用。这防止了用户在支付环节犹豫时名额被其他人抢走。

| 触发事件 | 名额处理 | 说明 |
|----------|----------|------|
| 用户点击"立即预约"（创建订单） | **占用**（booked_count +1） | 订单进入"待付款"状态，名额已被占用 |
| 支付成功 | **保持占用**（不变） | 订单进入"待使用"状态 |
| 支付超时取消 | **释放**（booked_count -1） | 订单进入"已取消"状态 |
| 用户取消预约（待使用状态） | **释放**（booked_count -1） | 订单进入"已取消"状态，走退款流程 |
| 修改时间 | 原时段释放 + 新时段占用（净变化为0，原子操作） | 先占用新时段成功，再释放原时段 |
| 过期 | **不释放** | 订单进入"已过期"状态，名额已浪费 |
| 门店核销 | **不释放**（已履约） | 订单进入下一状态 |

### 待付款订单名额保护

| 规则项 | 说明 |
|--------|------|
| 待付款超时时间 | 15分钟（可配置） |
| 超时后处理 | 订单自动取消，释放名额 |
| 超时前 | 名额被占用，其他用户看到该时段"已约满"或显示剩余名额 |

## 十、取消预约与退款关系

### 核心规则

> **取消预约 ≠ 退款，但取消预约自动触发退款流程。**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 用户点击"取消预约" | 进入预约详情页的取消确认页 |
| 2 | 确认取消 | 展示取消原因选择（选填）+ 退款提示 |
| 3 | 系统处理 | ①订单状态 → "已取消" ②同时创建退款单，走退款流程 |
| 4 | 退款到账 | 按原支付方式退回，微信支付通常 1-3 个工作日 |

### 退款与订单状态

| 订单状态 | 退款状态 | 说明 |
|----------|----------|------|
| 已取消 | 退款中 | 取消预约后自动创建退款单 |
| 已取消 | 已退款 | 退款完成（终态） |

> **退款状态机保持不变**（待处理→处理中→退款中→已完成/已拒绝/已取消），不在门店履约状态机中体现。

### 入口与页面关系

```
我的 → 我的预约 → 选择某个预约订单 → 订单详情页
                                        ├── [修改时间] → 时间选择器
                                        └── [取消预约] → 取消确认页
                                                          ├── 展示退款金额
                                                          ├── 取消原因（选填）
                                                          ├── [确认取消] → 取消+退款
                                                          └── [返回]
```

## 十一、"我的预约"入口与页面

### 入口位置

"我的"页面新增 **"我的预约"** 入口卡片，位于"我的订单"下方。

### 页面定位

聚合展示用户的所有门店预约订单（商品自提 + 体检到店），区别于普通快递/寄样订单。

### 订单筛选

| Tab | 包含状态 |
|-----|----------|
| 全部 | 全部预约订单 |
| 待付款 | pending_payment |
| 待使用 | pending_use |
| 检验中 | testing（仅体检到店） |
| 待评价 | pending_review |
| 已完成 | completed |
| 已取消/已过期 | 已取消 + 已过期 |

### 订单卡片展示

每个预约订单卡片展示：
- 订单类型标签（商品自提/体检预约）
- 门店名称 + 门店地址
- 预约时间（商品自提显示预计可取货时间，体检显示预约时段）
- 订单状态标签
- 金额
- 操作按钮（根据状态不同）

| 订单状态 | 卡片操作按钮 |
|----------|-------------|
| 待付款 | [去支付] |
| 待使用 | [修改时间] [取消预约] |
| 检验中 | [查看详情] |
| 待评价 | [去评价] |
| 已完成 | [查看详情] |
| 已取消/已过期 | [查看详情] |
