# B3. 状态流转 — 专项文档

---

## 一、商品订单状态

### 快递配送

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待发货 | pending_ship | 已支付，等待发货 | 支付成功 | 申请退款 |
| 待收货 | shipped | 已发货，等待收货 | 商家发货 | 确认收货、申请退款 |
| 待评价 | pending_review | 已收货，等待评价 | 用户确认收货 | 评价、申请售后 |
| 已完成 | completed | 订单完结 | 超过自动确认收货时间 / 用户评价 | 再次购买 |

### 门店自提

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待使用 | pending_use | 已支付，等待到店核销 | 支付成功 | 查看核销码、改期、申请退款 |
| 待评价 | pending_review | 已核销，等待评价 | 门店核销 | 评价 |
| 已完成 | completed | 订单完结 | 用户评价 / 超时自动完成 | 再次购买 |

## 二、体检订单状态

### 线上寄样体检（简化后）

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待寄出取样器 | pending_sampler | 已支付，等待商家寄出取样工具 | 支付成功 | 申请退款 |
| 待寄出样本 | pending_sample | 用户已收到工具，等待寄回样本 | 商家寄出取样器 | 申请退款 |
| 检验中 | testing | 样本已到，检验中 | 商家收到样本 | — |
| 待评价 | pending_review | 检验完成，等待评价 | 检验完成 | 评价、查看报告 |
| 已完成 | completed | 订单完结 | 用户评价 / 超时自动完成 | 查看报告、再次购买 |

> 已去掉的状态：已寄出取样器、已寄出样本、已收货待检验

### 线下门店预约

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待付款 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待使用 | pending_use | 已支付，等待到店核销 | 支付成功 | 查看核销码、改期、申请退款 |
| 检验中 | testing | 门店核销后开始处理 | 门店核销 | — |
| 待评价 | pending_review | 检验完成，等待评价 | 检验完成 | 评价、查看报告 |
| 已完成 | completed | 订单完结 | 用户评价 / 超时自动完成 | 查看报告、再次购买 |

## 三、订单列表 Tab 整合

### 商品订单 Tab

| Tab | 包含的订单状态 | 卡片展示的真实状态 |
|-----|--------------|-----------------|
| 待付款 | 快递配送(待付款) + 门店自提(待付款) | 各自显示"待付款" |
| 待发货/待使用 | 快递配送(待发货) + 门店自提(待使用) | 快递→"待发货" / 自提→"待使用" |
| 待收货 | 快递配送(待收货) | "待收货" |
| 待评价 | 快递配送(待评价) + 门店自提(待评价) | 各自显示"待评价" |
| 已完成 | 快递配送(已完成) + 门店自提(已完成) + 已过期 | 各自显示"已完成"/"已过期" |

### 体检订单 Tab

| Tab | 包含的订单状态 | 卡片展示的真实状态 |
|-----|--------------|-----------------|
| 待付款 | 寄样(待付款) + 到店(待付款) | 各自显示"待付款" |
| 待寄出取样器/待使用 | 寄样(待寄出取样器) + 到店(待使用) | 寄样→"待寄出取样器" / 到店→"待使用" |
| 待寄出样本 | 寄样(待寄出样本) | "待寄出样本" |
| 检验中 | 寄样(检验中) + 到店(检验中) | 各自显示"检验中" |
| 待评价 | 寄样(待评价) + 到店(待评价) | 各自显示"待评价" |
| 已完成 | 寄样(已完成) + 到店(已完成) + 已过期 | 各自显示"已完成"/"已过期" |

**退款/售后 Tab**：独立，不随履约方式变化。退款状态（待处理→处理中→退款中→已完成/已拒绝/已取消）保持不变。

## 四、状态流转图

### 商品订单

```
快递配送：
待付款 ──支付成功──→ 待发货 ──商家发货──→ 待收货 ──确认收货──→ 待评价 ──评价──→ 已完成

门店自提：
待付款 ──支付成功──→ 待使用 ──门店核销──→ 待评价 ──评价──→ 已完成
                       │
                       └──过期未到店──→ 已过期（展示在"已完成"Tab，标签为"已过期"）
```

### 体检订单

```
线上寄样：
待付款 ──支付成功──→ 待寄出取样器 ──商家寄出──→ 待寄出样本 ──商家收货──→ 检验中 ──完成──→ 待评价 ──评价──→ 已完成

线下门店预约：
待付款 ──支付成功──→ 待使用 ──门店核销──→ 检验中 ──完成──→ 待评价 ──评价──→ 已完成
                       │
                       └──过期未到店──→ 已过期（展示在"已完成"Tab，标签为"已过期"）
```

### 禁止流转

| 禁止 | 原因 |
|------|------|
| 待使用 → 已取消 | 已支付订单不可取消，只能申请退款 |
| 待评价/已完成/已过期 → 退款 | 已履约或已过期，不可退款 |
| 已过期 → 任何状态 | 终态 |

## 六、已过期规则

| 规则项 | 说明 |
|--------|------|
| 触发 | 系统定时任务，每天营业结束后扫描当天"待使用"状态门店订单 |
| 状态 | "待使用" → "已过期"（终态） |
| 退款 | 不退款 |
| 名额 | 不释放 |
| 核销码 | 自动失效 |
| 前端展示 | 不单独建Tab，展示在"已完成"Tab中，卡片标签为"已过期" |

---

## 七、改期规则

| 规则项 | 说明 |
|--------|------|
| 改期次数 | **不限次数** |
| 改期时间范围 | 可选未来任意日期+时段 |
| 改期截止 | 预约日之前（不含当天），当天及之后不可改期 |
| 不可改期 | 已核销、待评价、已完成、已过期、已取消、已退款 |
| 名额 | 原时段释放 + 新时段占用 |

---

## 八、核销码状态

| 订单状态 | 核销码状态 | 核销时行为 |
|----------|-----------|-----------|
| 待使用 | 有效 | 可核销 |
| 待评价/已完成 | 无效 | 提示"该订单已核销" |
| 已过期 | 无效 | 提示"该订单已过期" |
| 已取消/已退款 | 无效 | 提示"该订单已取消/已退款" |

---

## 九、预约名额释放规则

| 触发事件 | 名额处理 |
|----------|----------|
| 支付成功 | 占用（booked_count +1） |
| 支付超时取消 | 释放（booked_count -1） |
| 退款 | 释放（booked_count -1） |
| 改期 | 原时段释放 + 新时段占用（净变化为0） |
| 过期 | **不释放** |
| 门店核销 | 不释放（已履约） |
