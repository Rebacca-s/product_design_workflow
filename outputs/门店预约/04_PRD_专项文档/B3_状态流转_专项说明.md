# B3. 状态流转 — 专项文档

---

## 一、订单状态定义

### 商品自提订单

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待支付 | pending_payment | 订单已创建但未支付 | 用户提交订单 | 支付、取消 |
| 待使用 | pending_use | 已支付，等待用户到店 | 支付成功 | 查看核销码、申请退款 |
| 已核销 | verified | 门店已核销，用户已取货 | 门店确认核销 | 评价门店 |
| 已完成 | completed | 订单完结 | 核销后自动完成 | 评价门店、再次购买 |
| 已取消 | cancelled | 订单已取消（支付超时/用户取消） | 支付超时/用户主动取消 | 无 |
| 已退款 | refunded | 订单已退款 | 用户申请退款通过 | 无 |

### 体检预约订单

| 状态 | 状态值 | 含义 | 触发条件 | 可执行操作 |
|------|--------|------|----------|-----------|
| 待支付 | pending_payment | 订单已创建未支付 | 用户提交订单 | 支付、取消 |
| 待使用 | pending_use | 已支付，等待用户到店 | 支付成功 | 查看核销码、申请退款 |
| 已核销 | verified | 门店已核销，等待体检/报告 | 门店确认核销 | 评价门店 |
| 报告已上传 | report_uploaded | 门店已上传体检报告 | 门店上传报告 | 查看报告、评价门店 |
| 已完成 | completed | 订单完结 | 报告上传后自动完成（或无报告直接完成） | 查看报告、评价门店 |
| 已取消 | cancelled | 订单已取消 | 支付超时/用户主动取消 | 无 |
| 已退款 | refunded | 订单已退款 | 用户申请退款通过 | 无 |

## 二、状态流转图

### 商品自提订单

```
                  ┌─────────────┐
                  │  待支付      │
                  │pending_payment│
                  └──┬──────┬───┘
                     │      │
              支付成功│      │超时/取消
                     │      │
                     ↓      ↓
              ┌─────────┐ ┌──────────┐
              │ 待使用   │ │ 已取消    │
              │pending_  │ │cancelled │ (终态)
              │  use    │ └──────────┘
              └────┬────┘
                   │       ┌──────────┐
          用户退款 │       │ 已退款    │
                   │       │refunded  │ (终态)
                   │       └──────────┘
                   │
             门店核销│
                   ↓
            ┌───────────┐
            │  已核销    │
            │ verified  │
            └─────┬─────┘
                  │
          系统自动完成│
                  ↓
            ┌───────────┐
            │  已完成    │ (终态)
            │ completed │
            └───────────┘
```

### 体检预约订单

```
                  ┌─────────────┐
                  │  待支付      │

                  └──┬──────┬───┘
                     │      │
              支付成功│      │超时/取消
                     │      │
                     ↓      ↓
              ┌─────────┐ ┌──────────┐
              │ 待使用   │ │ 已取消    │
              │pending_  │ │cancelled │ (终态)
              │  use    │ └──────────┘
              └────┬────┘
                   │       ┌──────────┐
          用户退款 │       │ 已退款    │
                   │       │refunded  │ (终态)
                   │       └──────────┘
                   │
             门店核销│
                   ↓
            ┌───────────┐
            │  已核销    │
            │ verified  │
            └─────┬─────┘
                  │
          ┌───有报告？───┐
          ↓             ↓
         是             否
          ↓             ↓

          ↓             ↓
  ┌──────────────┐ ┌───────────┐
  │  报告已上传   │ │  已完成    │ (终态)
  │report_uploaded│ │ completed │
  └──────┬───────┘ └───────────┘
         │
  用户查看后完成│
         ↓
  ┌───────────┐
  │  已完成    │ (终态)
  │ completed │
  └───────────┘
```

## 三、状态流转规则表

| 当前状态 | 可流转到 | 触发条件 | 前置校验 |
|----------|----------|----------|----------|
| 待支付 | 待使用 | 用户支付成功 | 支付回调验证通过 |
| 待支付 | 已取消 | 支付超时（如30分钟） | 系统定时任务 |
| 待支付 | 已取消 | 用户主动取消 | 仅待支付可取消 |
| 待使用 | 已核销 | 门店确认核销 | 订单属于该门店 + 已支付 + 待使用 |
| 待使用 | 已退款 | 用户申请退款通过 | 未核销 |
| 已核销 | 已完成（商品） | 系统自动 | 核销后即时完成 |
| 已核销 | 报告已上传（体检） | 门店上传报告 | 该订单已有核销记录 |
| 已核销 | 已完成（体检） | 系统自动（无报告场景） | 核销后即时完成 |
| 报告已上传 | 已完成 | 系统自动 | 报告上传成功后即时完成 |
| 已核销 | 已取消 | **禁止** | 已核销订单不可取消 |
| 已核销 | 已退款 | **禁止** | 已核销订单不可退款 |

## 四、核销码状态

核销码本身不维护独立状态，其有效性由关联订单状态决定：

| 订单状态 | 核销码状态 | 核销时行为 |
|----------|-----------|-----------|
| 待使用 | 有效 | 可核销 |
| 已核销 | 无效 | 提示"该订单已核销" |
| 已完成 | 无效 | 提示"该订单已完成" |
| 已取消 | 无效 | 提示"该订单已取消" |
| 已退款 | 无效 | 提示"该订单已退款" |

## 五、预约名额释放规则

| 触发事件 | 名额处理 |
|----------|----------|
| 用户支付成功 | 占用名额（booked_count +1） |
| 支付超时取消 | 释放名额（booked_count -1） |
| 用户主动取消 | 释放名额（booked_count -1） |
| 退款 | 释放名额（booked_count -1） |
| 门店核销 | 不释放（已履约） |
