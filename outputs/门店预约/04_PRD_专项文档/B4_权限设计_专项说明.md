## 三、门店后台账号管理

### 账号创建（平台运营操作）

| 规则 | 说明 |
|------|------|
| 创建入口 | 平台总后台 → 门店管理 → 门店详情 → 账号管理 |
| 创建流程 | 输入账号（手机号）+ 初始密码 → 绑定门店 → 创建成功 |
| 门店人员首次登录 | 使用初始密码登录 → 强制修改密码 → 进入工作台 |
| 一门店多账号 | 一个门店可有多个工作人员账号 |
| 一账号一门店 | 一个账号只能绑定到一个门店 |
| 密码重置 | 门店人员忘记密码 → 联系平台运营重置（本期不做自服务） |
| 账号停用 | 平台运营可停用门店账号，停用后该账号无法登录 |

### 登录与校验

| 规则 | 说明 |
|------|------|
| 登录页 | 门店后台独立登录页（PC Web），输入手机号+密码 |
| 登录校验 | 校验账号是否存在、密码是否正确、账号是否被停用 |
| 门店状态校验 | 登录后校验绑定的门店状态，若门店已关闭则拒绝登录 |
| 数据隔离 | 所有API请求携带门店ID，后端校验数据归属 |

## 四、权限异常处理

| 场景 | 处理方式 | 用户提示 |
|------|----------|----------|
| 门店人员尝试核销非本门店订单 | 后端拒绝，返回403 | "该订单不属于本门店，无法核销" |
| 门店人员尝试查看其他门店订单 | 后端过滤，仅返回本门店数据 | 无提示（数据隔离） |
| 门店人员尝试新增商品 | 功能不可见 | 无入口 |
| 平台运营尝试核销订单 | 功能不可见 | 无入口 |
| 门店已关闭时门店人员登录 | 拒绝登录 | "本门店已停止服务，无法登录" |
