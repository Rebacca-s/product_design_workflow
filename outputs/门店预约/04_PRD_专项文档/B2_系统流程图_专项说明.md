## 一、系统交互总览

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  小程序C端   │ ←→  │   后端API    │ ←→  │   数据库     │
└─────────────┘     └──────────────┘     └─────────────┘
                           ↕
                    ┌──────────────┐
                    │  平台总后台   │
                    └──────────────┘
                           ↕
                    ┌──────────────┐
                    │   门店后台    │
                    └──────────────┘
```

## 二、关键数据流

### 2.1 平台配置→门店可用→小程序展示

```
平台总后台                    后端API                      数据库
    │                          │                           │
    │ 配置门店可售商品           │                           │
    │─────────────────────────→│                           │
    │                          │ store_product_relation     │
    │                          │───────────────────────────→│
    │                          │  写入关联表                 │
    │                          │←───────────────────────────│
    │←─────────────────────────│                           │
    │  配置成功                  │                           │
    │                          │                           │
    │                          │       门店后台              │
    │                          │◄══════════════════════════│
    │                          │  读取本门店已配置商品        │
    │                          │                           │
    │                          │       小程序               │
    │                          │◄══════════════════════════│
    │                          │  查询门店可售商品            │
    │                          │ (platform_assigned=true   │
    │                          │  AND is_available=true)    │
```

### 2.2 用户下单（门店履约）

```
  小程序                        后端API                      数据库
    │                              │                           │
    │ 选择商品+门店自提             │                           │
    │ 提交订单                     │                           │
    │─────────────────────────────→│                           │
    │                              │ 校验：                    │
    │                              │ - 商品在该门店可售         │
    │                              │ - 门店状态营业中           │
    │                              │ - 库存充足                │
    │                              │───────────────────────────→│
    │                              │←───────────────────────────│
    │                              │                           │
    │                              │ 创建订单                  │
    │                              │ - fulfillment_type=pickup │
    │                              │ - store_id=X              │
    │                              │ - 生成核销码              │
    │                              │───────────────────────────→│
    │                              │←───────────────────────────│
    │←─────────────────────────────│                           │
    │ 返回订单信息+核销码           │                           │
    │                              │                           │
    │ 支付订单                     │                           │
    │─────────────────────────────→│                           │
    │                              │ 更新支付状态              │
    │                              │ 订单状态 → 待使用          │
    │                              │───────────────────────────→│
    │←─────────────────────────────│                           │
    │ 支付成功                     │                           │
```

### 2.3 门店核销

```
  门店后台                      后端API                      数据库
    │                              │                           │
    │ 扫码/输入核销码              │                           │
    │─────────────────────────────→│                           │
    │                              │ 查询订单                  │
    │                              │───────────────────────────→│
    │                              │←───────────────────────────│
    │                              │                           │
    │                              │ 校验：                    │
    │                              │ - 核销码存在且未使用       │
    │                              │ - order.store_id=本门店   │
    │                              │ - order.status=待使用     │
    │                              │ - order.pay_status=已支付  │
    │                              │                           │
    │←─────────────────────────────│                           │
    │ 返回订单信息(确认弹窗)        │                           │
    │                              │                           │
    │ 确认核销                     │                           │
    │─────────────────────────────→│                           │
    │                              │ 幂等校验                  │
    │                              │                           │
    │                              │ 更新订单：                │
    │                              │ - status=已核销           │
    │                              │ - verified_at=now        │
    │                              │ - verified_by=门店人员ID   │
    │                              │───────────────────────────→│
    │                              │                           │
    │                              │ 写入核销记录              │
    │                              │───────────────────────────→│
    │                              │←───────────────────────────│
    │←─────────────────────────────│                           │
    │ 核销成功                     │                           │
    │                              │                           │
    │                              │  小程序(异步)              │
    │                              │  订单状态同步             │
    │                              │═══════════════════════════→│
```

### 2.4 体检报告上传与查看

```
  门店后台                      后端API                      数据库
    │                              │                           │
    │ 上传体检报告(PDF/图片)        │                           │
    │─────────────────────────────→│                           │
    │                              │ 校验：订单已核销          │
    │                              │ 上传文件到存储            │
    │                              │                           │
    │                              │ 写入报告记录              │
    │                              │ 更新订单status=报告已上传  │
    │                              │───────────────────────────→│
    │←─────────────────────────────│                           │
    │ 上传成功                     │                           │
    │                              │                           │
    │                              │  小程序                    │
    │                              │◄══════════════════════════│
    │                              │ 订单详情→查看报告         │
    │                              │ 返回报告文件URL列表        │
```

### 2.5 评价流程

```
  小程序                        后端API                      数据库
    │                              │                           │
    │ 提交评价(评分+文字+图片)      │                           │
    │─────────────────────────────→│                           │
    │                              │ 校验：订单已核销          │
    │                              │ 校验：该订单未评价        │
    │                              │                           │
    │                              │ 写入评价记录              │
    │                              │───────────────────────────→│
    │←─────────────────────────────│                           │
    │ 评价成功                     │                           │
    │                              │                           │
    │                              │  门店详情页(异步)          │
    │                              │  刷新评价列表+评分        │
    │                              │═══════════════════════════→│
```

## 三、关键接口摘要

| 接口 | 调用方 | 说明 |
|------|--------|------|
| GET /stores | 小程序 | 门店列表（支持经纬度、类型筛选、分页） |
| GET /stores/{id} | 小程序 | 门店详情（含可售商品、可预约服务、评价摘要） |
| GET /stores/{id}/products | 小程序 | 门店可售商品列表 |
| GET /stores/{id}/services | 小程序 | 门店可预约服务列表 |
| GET /stores/{id}/slots?date= | 小程序 | 某日可预约时段 |
| POST /orders | 小程序 | 创建订单（含履约方式、门店ID、预约时段） |
| GET /orders/{id} | 小程序/门店后台 | 订单详情（含核销码） |
| POST /orders/{id}/verify | 门店后台 | 核销订单 |
| POST /orders/{id}/report | 门店后台 | 上传体检报告 |
| POST /reviews | 小程序 | 提交评价 |
| GET /stores/{id}/reviews | 小程序 | 门店评价列表 |
| POST /admin/stores | 平台后台 | 创建/编辑门店 |
| PUT /admin/stores/{id}/products | 平台后台 | 配置门店商品 |
| PUT /admin/stores/{id}/services | 平台后台 | 配置门店服务 |
| GET /admin/verifications | 平台后台 | 核销记录列表 |

## 四、数据同步规则

| 场景 | 触发端 | 同步目标 | 同步策略 |
|------|--------|----------|----------|
| 平台配置门店商品 | 平台后台 | 门店后台、小程序 | 即时生效 |
| 门店下架商品 | 门店后台 | 小程序 | 即时生效（下次请求时过滤） |
| 门店修改营业时间 | 门店后台 | 小程序 | 即时生效 |
| 门店暂停预约 | 门店后台 | 小程序 | 即时生效 |
| 订单核销 | 门店后台 | 小程序订单详情 | 异步同步（轮询或推送） |
| 报告上传 | 门店后台 | 小程序订单详情 | 即时生效 |
| 用户评价 | 小程序 | 门店详情页、平台后台 | 即时生效 |
