# 原型说明文档 — 供货商管理

## 项目概况

| 属性 | 内容 |
|------|------|
| 产品名称 | 哆爱宠后台 - 供货商管理 |
| 终端类型 | PC Web 后台 |
| 页面数量 | 2 个页面 |
| 菜单归属 | 合作管理 > 供货商管理 / 供货商结算 |

## 页面清单

```
合作管理
├── 供货商管理    /cooperation/supplier
└── 供货商结算    /cooperation/supplier/settlement
```

## P1. 供货商管理

| 属性 | 说明 |
|------|------|
| 布局 | 表格(5列) + 顶部新增按钮 + 操作列(关联商品/货款结算) |
| 关联商品弹窗 | 下拉搜索选商品 + 结算单价输入 + 取消关联 |
| 5种状态 | Loading/正常/空数据/关联为空/无权限 |

## P2. 供货商结算

| 属性 | 说明 |
|------|------|
| 布局 | 供货商名称头部 + 单一结算列表(含待结算+已结算) |
| 确认结算弹窗 | 只读结算金额 + 实际付款信息填写 |
| 结算记录弹窗 | 历史已结算列表 |
| 5种状态 | Loading/正常/空数据/确认中/结算完成 |

## 全局设计规范

| 规范 | 值 |
|------|-----|
| 主色调 | #1890FF |
| 待结算 | 橙色标签 |
| 已结算 | 绿色标签 |
| 表格行高 | 48px |
| 弹窗宽度 | 520px |
