# PRD 产品需求文档 — 供货商管理 & 门店管理

> **文档版本**：v1.0 | **创建日期**：2026-07-30 | **状态**：待确认

## A1. 需求背景

哆爱宠后台"合作管理 → 供货商管理/门店管理"当前仅支持维护供货商名称。

【现有功能】缺乏供货商结算、门店管理、门店结算，财务人员需要在线下手工计算每月应结算金额。

本次在现有供货商管理基础上扩展：关联商品&结算定价 → 订单完成自动计算待结算 → 确认结算 → 生成结算记录并联动财务流水。门店管理新增，与供货商高度相似。

## 3. 待结算金额计算规则

- 供货商：Σ(关联商品结算单价 × 已完成未结算的该商品订单数量)
- 门店：Σ(关联品项结算单价 × 已完成未结算的该品项订单数量)

## 4. 与财务管理的联动

- 确认结算 → 自动生成财务流水（供货商货款支出 / 门店货款支出）
- 利润 = 实际收入 - 服务商提成 - 供货商成本 - **门店成本**

## A5. 功能说明

### 核心结论

合作管理模块包含四个独立子菜单：供货商管理 + 供货商结算 + 门店管理 + 门店结算。两者结构一致——列表+关联弹窗+结算页+确认结算弹窗。供货商关联商品（结算单价来自分销品项），门店关联体检品项（结算单价来自品项管理）。结算确认后自动生成财务流水（供货商货款支出 / 门店货款支出）。利润 = 实际收入 - 服务商提成 - 供货商成本 - **门店成本**。

## A8. 异常情况

| 编号 | 场景                   | 处理                     |
| ---- | ---------------------- | ------------------------ |
| E1   | 订单完成但未关联供货商 | 不产生待结算记录         |
| E2   | 结算单价未设置         | 关联商品时必填结算单价   |
| E3   | 结算金额与系统不一致   | 允许手动修改实际付款金额 |
| E4   | 重复确认结算           | 已结算行不显示确认按钮   |

## B1. 业务流程图

```
输入：新增供货商 → 关联商品+设结算单价
  ↓
处理：订单完成 → 自动计算待结算 → 月度汇总
  ↓
输出：待结算列表 → 确认结算 → 已结算记录 + 财务流水
```

