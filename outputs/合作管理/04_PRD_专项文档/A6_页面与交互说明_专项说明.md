## 交互说明


| 触发        | 落地                             |
| --------- | ------------------------------ |
| 「关联商品」    | 弹窗：下拉搜索选商品 → 添加（结算单价只读，来自分销品项） |
| 「取消关联」    | 移除商品绑定                         |
| 「货款结算」    | 跳转到供货商结算页面 + 自动筛选该供货商          |
| 供货商筛选     | 下拉选择供货商过滤结算列表（默认全部）            |
| 「查看详情」    | 展开订单明细                         |
| 「确认结算」    | 弹窗 → 填写付款信息 → 提交 → 列表刷新显示付款字段  |
| 「删除」(待结算) | 仅待结算行显示，点击确认 → 删除记录，对应订单恢复未结算  |
| 导出        | 导出当前筛选结果                       |


## 状态说明


| 状态      | 表现                    |
| ------- | --------------------- |
| Loading | 表格骨架屏                 |
| 列表为空    | "暂无供货商" / "暂无结算记录"    |
| 关联商品为空  | "暂未关联商品"              |
| 结算单价未配置 | 显示"--"，提示"请先在分销品项中配置" |
| 确认结算中   | 弹窗按钮 loading          |
| 结算完成    | Toast "结算确认成功" + 列表刷新 |

## P3. 门店管理

> 结构与 P1 供货商管理一致，差异点见下表。


| 差异点  | 供货商管理                    | 门店管理                     |
| ---- | ------------------------ | ------------------------ |
| 路由   | `/cooperation/supplier`  | `/cooperation/store`     |
| 列表列  | 名称/关联商品/累计结算/待结算/创建时间/操作 | 名称/关联品项/累计结算/待结算/创建时间/操作 |
| 操作列  | 关联商品 / 货款结算              | 关联品项 / 货款结算              |
| 新增弹窗 | 现有弹窗（仅名称）                | 新弹窗：门店名称(必填)             |
| 关联弹窗 | 下拉搜索商品，结算单价来自分销品项        | 下拉搜索体检品项，结算单价来自品项管理      |
