# A7 字段与规则说明 — 供货商管理

## 一、供货商列表字段

| 字段 | 类型 | 说明 |
|------|------|------|
| supplier_name | String | 供货商名称 |
| product_count | Integer | 关联商品数量 |
| total_settled | Decimal | 累计结算金额 |
| pending_amount | Decimal | 待结算金额（自动计算） |
| create_time | DateTime | 创建时间 |

## 二、关联商品字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| product_id | String | 是 | 关联商品ID（下拉搜索选取） |
| product_name | String | 是 | 商品名称（自动带入） |
| sale_price | Decimal | 只读 | 用户售价（自动带入） |
| settle_price | Decimal | 只读 | **结算单价**（来源于「分销品项」模块配置，不可在本弹窗修改。未配置时显示"--"） |

## 三、待结算金额计算

```
供货商待结算金额 = Σ(关联商品.settle_price × 该商品已完成且未结算的订单数量)
```

按自然月归入账期。

## 四、确认结算弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| supplier_name | String | 只读 | 自动带入 |
| period | String | 只读 | 账期 |
| settle_amount | Decimal | 只读 | 系统计算 |
| actual_amount | Decimal | **是** | 实际付款金额 |
| pay_time | DateTime | **是** | 付款时间 |
| pay_method | Enum | **是** | 线下结算 / 微信零钱 |
| remark | String | 否 | 备注 |

## 五、结算记录字段

| 字段 | 类型 | 说明 |
|------|------|------|
| settle_no | String | 结算编号 STL+YYYYMM+序号 |
| supplier_name | String | 供货商名称 |
| period | String | 账期 |
| order_count | Integer | 订单数量 |
| settle_amount | Decimal | 结算金额 |
| actual_amount | Decimal | 实际付款金额 |
| pay_method | String | 付款方式 |
| pay_time | DateTime | 付款时间 |
| operator | String | 确认人 |
| remark | String | 备注 |

## 六、结算详情（订单明细）字段

| 字段 | 类型 | 说明 |
|------|------|------|
| order_no | String | 订单号 |
| product_name | String | 商品名称 |
| quantity | Integer | 数量 |
| sale_price | Decimal | 售价 |
| settle_price | Decimal | 结算单价 |
| settle_amount | Decimal | 结算金额 = settle_price × quantity |
| complete_time | DateTime | 订单完成时间 |

## 七、状态枚举

| 状态 | 说明 |
|------|------|
| 待结算 | 订单已完成，等待财务确认付款 |
| 已结算 | 财务已确认付款，终态 |
