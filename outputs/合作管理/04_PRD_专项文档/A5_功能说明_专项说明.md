# A5 功能说明 — 供货商管理 & 供货商结算

> 本模块归属后台菜单：**合作管理 → 供货商管理**。
>
> **设计原则**：每个入口必须有落地。数据流闭环：新增供货商 → 关联商品 → 订单完成产生待结算 → 确认结算 → 生成结算记录+财务流水。

---

## 菜单结构

```
合作管理
├── 供货商管理      /cooperation/supplier          ← 供货商列表
└── 供货商结算      /cooperation/supplier/settlement ← 结算记录
```

> 两个独立子菜单。从供货商列表点击「货款结算」→ 跳转到供货商结算页面，自动筛选该供货商。

---

## G1. 供货商列表

### 筛选区

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 供货商搜索 | Input(带下拉) | 输入关键词搜索，下拉展示匹配的供货商名称，可点选 |
| 结算时间 | DateRangePicker | 选择结算时间范围后点击「货款结算」，以此为账期生成待结算记录 |
| 创建时间 | DateRangePicker | 按供货商创建时间范围筛选列表 |

### 列表字段

| 字段 | 说明 |
|------|------|
| 供货商名称 | 供货商名称 |
| 关联商品数量 | 已绑定商品数量 |
| 累计结算金额 | 历史已结算总金额 |
| 待结算金额 | 当前待结算金额（自动计算） |
| 创建时间 | 创建时间 |
| 操作 | 操作按钮组 |

### 操作列按钮

| 按钮 | 触发行为 | 落地 |
|------|----------|------|
| **关联商品** | 打开关联商品弹窗 | 关联商品弹窗（G2） |
| **货款结算** | 以「结算时间」筛选的范围作为账期，将该范围内已完成未结算的订单汇总生成待结算记录，跳转到供货商结算页面 | 供货商结算页（G3） |

> **结算时间逻辑**：必须先选择结算时间范围 → 点击「货款结算」→ 系统以该范围作为账期生成一条待结算记录（账期 = 结算时间起止日期）。未选择结算时间时，「货款结算」按钮置灰不可点击。

## G3. 供货商结算

### 入口
菜单：合作管理 > 供货商结算。或从供货商列表点击「货款结算」跳转。

### 筛选区

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 供货商搜索 | Input(带下拉) | 输入关键词搜索，下拉展示匹配的供货商名称，可点选 |
| 状态 | Select | 全部 / 待结算 / 已结算 |
| 创建时间 | DateRangePicker | 按账单生成时间（创建时间）范围筛选 |

### 设计
**所有供货商的待结算与已结算合并展示**，通过状态列区分。

### 列表字段

| 字段 | 说明 |
|------|------|
| 供货商名称 | 供货商 |
| 账期 | 结算周期（如 2026-07-01 至 2026-07-31） |
| 订单数 | 关联订单数量 |
| 结算金额 | 系统计算的应付款金额 |
| **实际付款金额** | 确认结算时填写的实际打款金额（待结算时为空） |
| 创建时间 | 账单生成时间 |
| 状态 | 待结算 / 已结算 |
| **付款时间** | 确认结算时填写的打款时间（待结算时为空） |
| **付款方式** | 线下结算 / 微信零钱（待结算时为空） |
| **备注** | 确认结算时填写的备注（待结算时为空） |
| 操作 | 操作按钮 |

> **删除规则**：仅待结算状态可删除。删除后该笔待结算记录移除，对应订单恢复为"未结算"状态。已结算记录不可删除。

### 待结算金额计算规则

```
供货商待结算金额 = Σ(关联商品结算单价 × 已完成但未结算的订单数量)
```

| 触发条件 | 说明 |
|----------|------|
| 订单状态变为"已完成" | 该订单涉及的商品产生待结算记录 |
| 结算确认完成 | 对应待结算记录转为已结算，从待结算金额中扣除 |

## G4. 确认结算

### 入口
供货商结算 Tab → 待结算行 → 操作列「确认结算」按钮。

### 弹窗字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 供货商名称 | 只读 | — | 自动带入 |
| 账期 | 只读 | — | 自动带入 |
| 结算金额 | 只读 | — | 系统计算的应付款金额 |
| **实际付款金额** | Input(数字) | **是** | 实际打款金额 |
| **付款时间** | DatePicker | **是** | 线下打款时间 |
| **付款方式** | Radio | **是** | 单选：◉ 线下结算  ○ 微信零钱 |
| **备注** | Textarea | 否 | 备注 |

### 操作流程

```
点击「确认结算」→ 填写实际付款信息 → 提交
    ↓
系统操作：
  ① 该行状态：待结算 → 已结算
  ② 列表刷新，该行显示实际付款金额/付款时间/付款方式/备注
  ③ 自动生成财务流水（供货商货款支出）
  ④ 更新供货商累计结算金额
```

---

## G5. 与财务管理的联动

| 联动点 | 说明 |
|--------|------|
| 确认结算 → 财务流水 | 自动生成支出流水（供货商货款支出） |
| 财务概览-供货商支出 | 本月供货商支出 = SUM(本月确认结算的实际付款金额) |
| 利润计算 | 利润 = 实际收入 - 服务商提成 - **供货商成本** |

| 供货商结算列表 | 当前筛选条件的结算记录 |

## 模块三：分销品项 — 结算单价配置

> 供货商和门店的结算单价来源于此。

### 背景

极差分销 → 分销品项中，已有对每个商品/体检品项配置**服务商提成**的能力（提成比例或固定金额）。【现有功能】

### 新增配置项

在分销品项的商品/品项配置中，增加两个配置选项：

| 配置项 | 适用对象 | 说明 |
|--------|----------|------|
| **供货商结算单价** | 商品品项 | 该商品对应的供货商结算单价（元） |
| **门店结算单价** | 体检品项 | 该品项对应的门店结算单价（元） |

> 配置后，供货商管理关联商品弹窗和门店管理关联品项弹窗中的"结算单价"字段自动读取此处配置值。
