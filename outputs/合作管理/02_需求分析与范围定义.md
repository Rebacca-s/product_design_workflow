# 需求分析与范围定义 — 合作管理（供货商 + 门店）

## 1. 用户角色

| 角色     | 使用场景                                                |
| -------- | ------------------------------------------------------- |
| 财务人员 | 管理供货商/门店、核对待结算账单、确认结算、查看结算记录 |
| 管理人员 | 查看结算情况                                            |

## 2. 功能范围

### P0 — 供货商管理

| 编号 | 功能         | 说明                                                                                                          |
| ---- | ------------ | ------------------------------------------------------------------------------------------------------------- |
| G1   | 供货商管理   | 列表（名称/关联商品/累计结算/待结算/创建时间）+ 操作（关联商品/货款结算）                                     |
| G2   | 关联商品弹窗 | 下拉搜索选商品 → 添加（用户售价和结算单价只读，结算单价来自分销品项）+ 取消关联                               |
| G3   | 供货商结算   | 待结算+已结算合并列表（11列：供货商/账期/订单数/结算金额/实际付款/生成时间/状态/付款时间/付款方式/备注/操作） |

### P0 — 门店管理

| 编号 | 功能         | 说明                                                                                                        |
| ---- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| S1   | 门店管理     | 列表（名称/关联品项/累计结算/待结算/创建时间）+ 操作（关联品项/货款结算）                                   |
| S2   | 关联品项弹窗 | 下拉搜索选体检品项 → 添加（用户售价和结算单价只读，结算单价来自品项管理）+ 取消关联                         |
| S3   | 门店结算     | 待结算+已结算合并列表（11列：门店/账期/订单数/结算金额/实际付款/生成时间/状态/付款时间/付款方式/备注/操作） |

### P0 — 共用

| 编号 | 功能      | 说明                                                                             |
| ---- | --------- | -------------------------------------------------------------------------------- |
| C1   | 确认结算  | 弹窗：实际付款金额/付款时间/付款方式(单选:线下结算/微信零钱)/备注 → 生成财务流水 |
| C2   | Excel导出 | 列表/结算列表/订单明细                                                           |

### 新增门店弹窗

| 字段     | 必填 | 说明     |
| -------- | ---- | -------- |
| 门店名称 | 是   | 门店名称 |

| 模块         | 改动                                                  |
| ------------ | ----------------------------------------------------- |

## 3. 待结算金额计算规则

- 供货商：Σ(关联商品结算单价 × 已完成未结算的该商品订单数量)
- 门店：Σ(关联品项结算单价 × 已完成未结算的该品项订单数量)

## 4. 与财务管理的联动

- 确认结算 → 自动生成财务流水（供货商货款支出 / 门店货款支出）
- 利润 = 实际收入 - 服务商提成 - 供货商成本 - **门店成本**
