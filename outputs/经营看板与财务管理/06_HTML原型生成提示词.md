# HTML 原型生成提示词 — 经营看板 & 财务管理

> 复制以下内容到 Cursor / Claude 生成可交互 HTML 原型。

---

## Prompt

```
你是一个资深前端工程师，请为"哆爱宠"宠物服务平台的后台管理系统生成"经营看板"和"财务管理"两个页面的 HTML 原型。

## 产品背景
哆爱宠是宠物服务平台，提供商品销售、宠物体检、活动报名等服务。后台管理系统需要两个数据看板页面：
- 经营看板：面向老板和运营，展示业务增长数据
- 财务管理：面向财务人员，展示资金数据

## 页面要求

请生成一个包含侧边导航的 HTML 文件，包含两个 Tab/菜单切换：

### Tab 1：经营看板 (`/dashboard`)
长滚动页面，包含：

**1. 核心指标卡片（顶部时间筛选：今日/昨日/本周/本月）**
- 订单组(4个卡片)：订单数量 128 | 支付订单 120 | 支付金额 ¥35,800 | 客单价 ¥298
- 用户组(3个卡片)：新增用户 45 | 新增会员 12 | 活跃用户 256
- 商品组(2个卡片)：商品销量 98 | 商品销售额 ¥28,500
- 体检组(2个卡片)：体检订单 22 | 体检销售额 ¥7,300

**2. 订单趋势** — 双线折线图（蓝色=订单数 / 绿色=支付金额），日/周/月切换

**3. 销售分析** — 左右分栏：左=商品vs体检销售额趋势双线图，右=销售占比环形图(商品70%/体检30%)

**4. 商品分析** — 排行表格(排名/商品名称/销量/销售额)，TOP10，支持销量排行/销售额排行切换

**5. 体检业务分析** — 左=体检套餐排行TOP10表格，右=订单状态分布饼图(待寄样30%/检测中45%/已完成25%)

**6. 用户分析** — 左=新增用户趋势折线图，右=用户来源横向柱状图(朋友推荐/二维码/搜索/其他)

### Tab 2：财务管理 (`/finance`)
三个子Tab切换页：

**子Tab 2.1：财务概览**
- 指标卡：累计/本月/今日收入 + 累计/本月/今日退款 + 实际收入 + 利润
- 3条趋势折线图：收入趋势、支出趋势(提成)、利润趋势

**子Tab 2.2：财务流水**
- 筛选区 + 表格(流水编号/类型/业务类型/订单号/订单明细/金额/时间/备注)
- 金额：收入绿色+号，支出红色-号
- 分页器 + 导出按钮

**子Tab 2.3：财务报表**
- 维度切换(按日/按月) + 时间选择
- 汇总卡(订单收入/退款/提成/利润)
- 收入vs支出vs利润趋势图
- 明细表格 + 导出按钮

## 数据要求
- 所有数据使用真实感的宠物相关中文数据（猫粮套餐、狗狗体检、猫咪基因检测等）
- 供货商数据模拟：XX宠物医院(体检)、YY宠物用品(商品)、ZZ检测机构(体检)
- 用户来源数据模拟：朋友推荐 45%、二维码推广 30%、搜索引擎 15%、其他 10%
- 图表数据覆盖近30天

## 设计风格
- PC 后台浅色主题，主色调 #1890FF
- 使用 Chart.js CDN：https://cdn.jsdelivr.net/npm/chart.js
- 收入/利润/增长用绿色 #52C41A
- 支出/退款用红色 #FF4D4F
- 卡片白色背景，4px圆角，阴影
- 单文件 HTML，内嵌 CSS/JS

## 交互要求
- 菜单切换流畅
- 时间筛选联动所有指标
- 图表 hover 有 tooltip
- 导出按钮点击有 loading 模拟
- 响应式最小宽度 1200px
```
