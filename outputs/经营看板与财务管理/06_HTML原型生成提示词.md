# HTML 原型生成提示词 — 经营看板 & 财务管理

> 复制以下内容到 Cursor / Claude 生成可交互 HTML 原型。

---

## Prompt

```
你是一个资深前端工程师，请为"哆爱宠"宠物服务平台的后台管理系统生成"经营分析"和"财务管理"两个一级菜单下的页面 HTML 原型。

## 产品背景
哆爱宠是宠物服务平台，提供商品销售、宠物体检、活动报名等服务。后台管理系统需要：
- 经营分析：面向老板和运营，展示业务增长数据（经营看板 + 品项销售）
- 财务管理：面向财务人员，展示资金数据（资金概况 + 财务概览 + 财务流水）

## 页面要求

请生成一个包含侧边导航的 HTML 文件，侧边导航结构：

- 经营分析
  - 经营看板 (/dashboard)
  - 品项销售 (/item-sales)
- 财务管理
  - 资金概况 (/finance/capital-overview)
  - 财务概览 (/finance/financial-overview)
  - 财务流水 (/finance/financial-flow)

### 页面 1：经营看板 (/dashboard)
长滚动页面，含顶部时间筛选（今日/昨日/本周/本月/自定义）+ 环比基准切换（较昨日/较上周/较上月），下方 8 个卡片：

1. 核心经营指标：12个指标卡（订单4/用户3/商品2/体检2），每个含数值+环比增长率+环比基准
2. 财务趋势：三线折线图（商品收入/体检收入/总收入）
3. 订单趋势：三线折线图（商品订单/体检订单/总订单）
4. 收入结构分析：环形图（商品收入 vs 体检收入）
5. 品项贡献分析：横向条形图 TOP5/10/20，按销售额降序，含贡献率
6. 体检业务分析：漏斗图（待付款→待寄出取样器→已收货待检验→检验中→已完成→已退款）
7. 商品订单转化漏斗：漏斗图（待付款→待发货→待收货→待评价→已完成→已退款）
8. 用户分析：折线图（新增用户数）

### 页面 2：品项销售 (/item-sales)
Tab切换（商品/体检），每个视图含：
- 筛选：名称搜索 + 分类/类型 + 时间范围
- 表格：名称/分类/销量/销售金额/平均售价/订单数/退款数/退款金额/实际销售金额（9列）
- 排序：列头点击切换
- 导出Excel按钮

### 页面 3：资金概况 (/finance/capital-overview)
- 7个指标卡：账面余额/待退款/待供货商结算/待门店结算/待KA服务商提成/待Pro服务商提成/可用资金
- 资金趋势折线图（账面余额/收入/支出）
- 资金占用饼图（可用/供货商/门店/退款/KA提成/Pro提成）
- 快捷入口链接

### 页面 4：财务概览 (/finance/financial-overview)
- 顶部全局时间筛选器 [日][周][月][年][时间选择器]（控制所有图表和报表）
- 指标卡：收入/退款/实际收入/已结算支出明细/利润（均为4档：累计/本年/本月/今日）
- 已结算支出明细表格：供货商货款/门店货款/KA服务商提成/Pro服务商提成（4项×4档）
- 4个趋势图（各有独立局部时间筛选器）：
  - 资金趋势（三线：实际收入/支出/利润）
  - 支出趋势（堆叠：供货商货款/门店货款/KA提成/Pro提成）
  - 退款趋势（折线）
  - 利润趋势（折线）
- 财务明细报表：按日/按月维度 + 明细表格（订单收入/退款/KA提成/Pro提成/供货商货款/门店货款/实际收入/利润）+ 导出Excel

### 页面 5：财务流水 (/finance/financial-flow)
- 筛选区：时间范围 + 流水类型 + 业务类型（8种）+ 订单号搜索
- 表格：流水编号/类型/业务类型/订单号/订单明细/数量/金额/时间/备注
- 金额：收入绿色+号，支出红色-号
- 分页 + 导出Excel

## 数据要求
- 所有数据使用真实感的宠物相关中文数据（猫粮套餐、狗狗体检、猫咪基因检测等）
- 供货商数据模拟：XX宠物医院(体检)、YY宠物用品(商品)、ZZ检测机构(体检)
- 服务商数据：KA服务商（一级）、Pro服务商（二级）
- 图表数据覆盖近30天

## 设计风格
- PC 后台浅色主题，主色调 #1890FF
- 使用 Chart.js CDN：https://cdn.jsdelivr.net/npm/chart.js
- 收入/利润/增长用绿色 #52C41A
- 支出/退款用红色 #FF4D4F
- 卡片白色背景，4px圆角，阴影
- 单文件 HTML，内嵌 CSS/JS

## 交互要求
- 菜单切换流畅（侧边导航）
- 全局时间筛选联动所有图表和报表，局部时间筛选单独覆盖
- 图表 hover 有 tooltip
- 导出按钮点击有 loading 模拟
- 响应式最小宽度 1200px
```
