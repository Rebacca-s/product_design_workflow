# 原型说明文档 — 经营看板 & 财务管理

## 一、项目概况

| 属性 | 内容 |
|------|------|
| 产品名称 | 哆爱宠后台 - 经营看板 & 财务管理 |
| 终端类型 | PC Web 后台管理系统 |
| 设计风格 | 简洁专业的企业后台风格，浅色主题，数据可视化驱动 |
| 页面数量 | 2 个一级菜单页面 |
| 核心技术 | Vue/React + 组件库(Element Plus/Ant Design) + ECharts |

## 二、页面清单与跳转关系

```
后台导航
├── 📊 经营看板      /dashboard              老板/运营/管理可见
├── 💰 财务管理      /finance                老板/财务/管理可见
├── 🤝 合作管理
│   └── 供货商管理   /cooperation/supplier    财务/管理可见
│       ├── 供货商列表
│       ├── 供货商详情
│       └── 供货商结算（待结算/已结算）
├── ... (其他已有菜单)

跳转关系：
- 经营看板和财务管理为两个独立菜单，无直接跳转
- 经营看板指标卡片 → 可下钻到对应明细页(P1)
- 财务流水订单号 → 新标签页打开订单详情
- 财务管理 Tab 切换：概览 | 财务流水 | 财务报表
- 供货商列表 → 点击名称 → 供货商详情
- 供货商结算确认 → 自动生成财务流水（供货商货款支出 / 门店货款支出）
```

## 三、页面设计要点

### P1. 经营看板

| 属性 | 说明 |
|------|------|
| 布局 | 长滚动页面，顶部时间筛选+指标卡片，下方 5 个图表卡片纵向排列 |
| 指标卡 | 4组12个StatCard：订单(4)、用户(3)、商品(2)、体检(2)，每组横向排列 |
| 订单趋势 | 双线折线图 Card，内嵌日/周/月切换 |
| 销售分析 | 左右分栏：左侧销售额双线图，右侧环形占比图 |
| 商品分析 | Table Card，排名+商品+销量+销售额，顶部销量/销售额切换 |
| 体检分析 | 左右分栏：左侧排行 Table，右侧状态分布饼图 |
| 用户分析 | 左右分栏：左侧增长趋势折线图，右侧来源分布图 |

**5种状态**：Loading骨架屏 → 正常 → 空数据(新平台0值) → 部分失败(个别指标--) → 无权限

### P2. 财务管理

| 属性 | 说明 |
|------|------|
| 布局 | Tab 切换页：财务概览(默认)、财务流水、财务报表 |
| 概览 | 4组指标卡(收入3指标/退款3指标/实际收入/利润) + 3条趋势折线图 |
| 流水 | 筛选区 + 表格(5列) + 分页 |
| 报表 | 维度切换 + 4个汇总卡 + 趋势图 + 明细表格 + 导出 |

**5种状态**：同经营看板 + 流水空状态 + 导出loading/完成/失败
