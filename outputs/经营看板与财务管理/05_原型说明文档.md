# 原型说明文档 — 经营看板 & 财务管理

## 一、项目概况

| 属性 | 内容 |
|------|------|
| 产品名称 | 哆爱宠后台 - 经营分析 & 财务管理 |
| 终端类型 | PC Web 后台管理系统 |
| 设计风格 | 简洁专业的企业后台风格，浅色主题，数据可视化驱动 |
| 一级菜单 | 经营分析、财务管理（另与合作管理联动） |
| 核心技术 | Vue/React + 组件库(Element Plus/Ant Design) + ECharts |

## 二、页面清单与跳转关系

```
后台导航
├── 📊 经营分析
│   ├── 经营看板  /dashboard                    老板/运营/管理可见
│   └── 品项销售  /item-sales                   老板/运营/管理可见
├── 💰 财务管理
│   ├── 资金概况  /finance/capital-overview     老板/财务/管理可见
│   ├── 财务概览  /finance/financial-overview   老板/财务/管理可见（含财务明细报表）
│   └── 财务流水  /finance/financial-flow       老板/财务/管理可见
└── 🤝 合作管理（独立设计，见 outputs/合作管理/）

跳转关系：
- 经营看板品项贡献 → 跳转品项销售页
- 资金概况快捷入口：待退款→售后、待供货商结算/待门店结算→合作管理结算、待KA/Pro提成→分销管理
- 财务概览支出明细点击 → 跳转财务流水对应业务类型筛选
- 财务流水订单号 → 新标签页打开订单详情
```

## 三、页面设计要点

### P1. 经营看板

| 属性 | 说明 |
|------|------|
| 布局 | 长滚动页面，顶部时间筛选+环比基准，下方 8 个卡片纵向排列 |
| 核心指标 | 4组12个StatCard（订单/用户/商品/体检），每个含环比增长率+环比基准标签 |
| 财务趋势 | 三线折线图（商品收入/体检收入/总收入），日/周/月/年切换 |
| 订单趋势 | 三线折线图（商品订单/体检订单/总订单），日/周/月/年切换 |
| 收入结构 | 环形图（商品收入 vs 体检收入） |
| 品项贡献 | 横向条形图 TOP5/10/20，按销售额降序，含贡献率 |
| 体检漏斗 | 漏斗图 6 阶段（待付款→待寄出取样器→已收货待检验→检验中→已完成→已退款） |
| 商品漏斗 | 漏斗图 6 阶段（待付款→待发货→待收货→待评价→已完成→已退款） |
| 用户分析 | 折线图（新增用户数），日/周/月/年切换 |

### P2. 品项销售

| 属性 | 说明 |
|------|------|
| 布局 | Tab 切换：商品 / 体检 |
| 筛选 | 名称搜索 + 分类/类型筛选 + 时间范围（日/周/月/年+时间选择器） |
| 列表 | 9字段：名称/分类/销量/销售金额/平均售价/订单数/退款数/退款金额/实际销售金额 |
| 排序 | 默认按实际销售金额降序，支持销售金额/销售数量/订单数量切换 |
| 导出 | 导出当前筛选结果为 Excel |

### P3. 资金概况

| 属性 | 说明 |
|------|------|
| 布局 | 7个指标卡 + 资金趋势图 + 资金占用饼图 |
| 指标卡 | 账面余额/待退款/待供货商结算/待门店结算/待KA服务商提成/待Pro服务商提成/可用资金 |
| 资金趋势 | 折线图（账面余额/收入/支出），日/周/月/年+时间选择器 |
| 占用饼图 | 可用资金/供货商结算/门店结算/退款/KA提成/Pro提成 |
| 快捷入口 | 账面余额→财务流水、待退款→售后、待供货商/门店结算→合作管理结算、待KA/Pro提成→分销管理 |

### P4. 财务概览

| 属性 | 说明 |
|------|------|
| 全局时间 | 页面顶部全局时间筛选器 [日][周][月][年][时间选择器]，控制所有图表和报表 |
| 指标卡 | 收入/退款/实际收入/已结算支出明细/利润，均为4档（累计/本年/本月/今日） |
| 趋势图 | 资金趋势（三线）/支出趋势（堆叠）/退款趋势/利润趋势，各有局部时间筛选器 |
| 财务明细报表 | 按日/按月维度 + 明细表格（订单收入/退款/KA提成/Pro提成/供货商货款/门店货款/实际收入/利润）+ 导出Excel |

**双层时间筛选**：全局时间筛选器一键切换所有图表和报表；每个图表/报表有独立局部时间筛选器，可单独覆盖全局设置。

### P5. 财务流水

| 属性 | 说明 |
|------|------|
| 筛选 | 时间范围 + 流水类型 + 业务类型（8种）+ 订单号搜索 |
| 列表 | 9字段：流水编号/类型/业务类型/订单号/订单明细/数量/金额/时间/备注 |
| 业务类型 | 商品订单收入/体检订单收入/活动订单收入/退款支出/KA服务商提成支出/Pro服务商提成支出/供货商货款支出/门店货款支出 |
| 金额 | 收入绿色+号，支出红色-号 |
| 导出 | 导出当前筛选结果为 Excel |

**5种状态**：Loading骨架屏 → 正常 → 空数据 → 部分失败 → 无权限
