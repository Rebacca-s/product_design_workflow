# B1 业务流程图 — 经营看板 & 财务管理

    │  商品/套餐信息            │  支付时间                │
    │                         │                        │
    └─────────┬───────────────┴───────────┬────────────┘
              │                           │
              ▼                           ▼
        ┌─────────────────────────────────────┐
        │          经营看板数据聚合              │
        │                                    │
        │  核心指标卡片                        │
        │  ├── 订单组：订单数/支付订单/GMV/客单价 │
        │  ├── 用户组：新增/会员/活跃            │
        │  ├── 商品组：销量/销售额              │
        │  └── 体检组：订单数/销售额            │
        │                                    │
        │  趋势图表                            │
        │  ├── 订单趋势（订单数+支付金额）        │
        │  ├── 销售趋势（商品+体检）            │
        │  └── 用户增长趋势                    │
        │                                    │
        │  排行分析                            │
        │  ├── 商品销量/销售额排行               │
        │  └── 体检套餐排行                    │
        │                                    │

        │  ├── 体检订单状态分布                 │

        └─────────────────────────────────────┘
              │
              ▼
         经营看板页面展示
```

    │  支付金额                 │  退款金额                │  提成金额                │  结算金额
    │  支付时间                 │  退款时间                │  关联订单                │  供货商名称
    │                         │                        │                        │
    └─────────┬───────────────┴───────────┬────────────┴───────────┬────────────┘
              │                           │                        │
              ▼                           ▼                        ▼
        ┌──────────────────────────────────────────────────────────┐
        │          财务管理数据聚合                                   │
        │                                    │
        │  财务概览                            │
        │  ├── 收入指标：累计/本年/本月/今日      │
        │  ├── 退款指标：累计/本年/本月/今日      │
        │  ├── 实际收入 = 收入 - 退款           │

        │  ├── 已结算支出明细（供货商货款/门店货款/KA提成/Pro提成） │
        │  ├── 资金趋势/支出趋势/退款趋势/利润趋势  │
        │  └── 财务明细报表（按日/月 + 导出）     │
        │                                    │
        │  财务流水                            │
        │  ├── 支付成功 → 收入流水              │
        │  ├── 退款成功 → 退款流水              │
        │  ├── KA提成生成 → KA提成流水          │
        │  ├── Pro提成生成 → Pro提成流水        │
        │  └── 供货商/门店结算 → 货款流水        │
        └─────────────────────────────────────┘
              │
              ▼
         财务管理页面展示
```

## 三、用户使用流程

### 老板每日查看流程

```
打开后台 → 经营看板（默认今日）
    │
    ├── 扫一眼核心指标（GMV/订单/用户）
    ├── 看订单趋势（今天 vs 昨天）
    ├── 看商品排行（什么卖得好）
    │
    └── 切换到财务管理
        ├── 看今日收入/利润
        └── 结束
```

### 运营每周分析流程

```
打开后台 → 经营看板 → 切换到"本周"
    │
    ├── 看核心指标（本周 GMV 达标？）
    ├── 看订单趋势（哪天是高峰？）
    ├── 看销售占比（商品 vs 体检比例是否合理？）
    ├── 看商品排行（是否需要调整推广？）
    ├── 看体检履约状态（待寄样积压？催办！）
    ├── 看用户增长（新增用户趋势？来源？）
    └── 导出商品排行数据 → 周会汇报
```

### 财务月度对账流程

```
打开后台 → 财务管理 → 财务概览
    │
    ├── 核对本月收入 vs 微信支付商户后台
    ├── 核对本月退款 vs 售后记录
    ├── 核对本月服务商提成支出 vs 分销管理
    ├── 核对本月供货商成本 vs 供货商管理
    │
    ├── 切换到财务流水 → 按订单号搜索 → 追溯差异订单
    │
    └── 财务概览 → 财务明细报表 → 月度维度 → 导出 → 税务申报
```

### 供货商结算全流程（数据输入→处理→输出闭环）

```
第一步：数据输入
    │
    ├── 「新增供货商」→ 填写基础信息（名称）
    │
    ├── 「关联商品」→ 选择平台商品/套餐 → 设置结算单价
    │       结算单价是后续所有待结算金额的计算基础
    │
    └── 系统关联完成，供货商与商品/套餐绑定

第二步：自动处理
    │
    ├── 用户下单购买供货商关联的商品/套餐
    ├── 订单完成（状态变为"已完成"）
    ├── 系统自动计算：该订单产生的供货商待结算金额 = 结算单价 × 购买数量
    ├── 每月1日系统自动汇总上月各供货商的待结算账单
    │
    └── 供货商列表"待结算金额"自动更新

第三步：结算操作
    │
    ├── 财务查看供货商列表 → 点击「去结算」
    ├── 进入结算页 → 查看待结算列表（按账期）
    ├── 点击「查看详情」→ 展开订单明细，核对每笔订单
    │
    ├── 财务线下完成银行转账付款
    │
    ├── 回到系统 → 点击「确认结算」
    │   ├── 填写：实际付款金额 / 付款时间 / 付款方式 / 备注
    │   └── 提交
    │
    └── 系统自动：
        ├── 待结算 → 已结算
        ├── 写入结算记录表
        ├── 生成财务流水（供货商货款支出 / 门店货款支出）
        ├── 更新供货商累计结算金额
        └── 更新财务概览供货商支出指标

第四步：数据输出
    │
    ├── 已结算记录 Tab → 查看所有历史结算
    ├── 「结算记录」弹窗 → 按供货商查看结算历史
    ├── Excel 导出（供货商列表/待结算/已结算）
    └── 财务管理：利润 = 实际收入 - KA服务商提成 - Pro服务商提成 - 供货商货款 - 门店货款
```
