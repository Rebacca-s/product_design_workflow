# A6 页面与交互说明 — 经营看板 & 财务管理

## 页面清单

| 编号 | 页面     | 路由                          | 菜单                | 角色           |
| ---- | -------- | ----------------------------- | ------------------- | -------------- |
| P1   | 经营看板 | `/dashboard`                  | 经营分析 > 经营看板 | 老板/运营/管理 |
| P2   | 品项销售 | `/item-sales`                 | 经营分析 > 品项销售 | 老板/运营/管理 |
| P3   | 资金概况 | `/finance/capital-overview`   | 财务管理 > 资金概况 | 老板/财务/管理 |
| P4   | 财务概览 | `/finance/financial-overview` | 财务管理 > 财务概览 | 老板/财务/管理 |
| P5   | 财务流水 | `/finance/financial-flow`     | 财务管理 > 财务流水 | 老板/财务/管理 |

**菜单结构**：

```
经营分析
├── 经营看板  (/dashboard)
└── 品项销售  (/item-sales)

财务管理
├── 资金概况  (/finance/capital-overview)
├── 财务概览  (/finance/financial-overview)   ← 含财务明细报表区块
└── 财务流水  (/finance/financial-flow)
```

**跳转关系**：经营看板指标卡片可下钻到对应明细页（P1）。财务流水订单号可跳转订单详情。经营看板品项贡献可跳转品项销售页。

| 订单趋势-维度切换  | 仅订单趋势图刷新                                    |

| 无权限       | "您没有访问经营看板的权限"                                  |
