# A6 页面与交互说明 — 经营看板 & 财务管理

## 页面清单

| 编号 | 页面 | 路由 | 菜单 | 角色 |
|------|------|------|------|------|
| P1 | 经营看板 | `/dashboard` | 一级菜单：经营看板 | 老板/运营/管理 |
| P2 | 财务管理 | `/finance` | 一级菜单：财务管理 | 老板/财务/管理 |

**跳转关系**：两个页面独立，互不跳转。经营看板指标卡片可下钻到对应明细页（P1）。财务流水订单号可跳转订单详情。

### ③ 页面元素说明

| 序号 | 元素 | 组件类型 | 说明 |

| 8 | 收入结构环形图 | DoughnutChart | 商品收入 vs 体检收入，含图例 |
| 9 | 品项贡献条形图 | HorizontalBarChart | TOP N 可切换，按销售额降序 |
| 10 | TOP 切换按钮组 | ButtonGroup | TOP5 / TOP10 / TOP20，默认 TOP10 |
| 11 | 体检转化漏斗图 | FunnelChart | 5 阶段漏斗 + 转化率标注 |
| 12 | 商品转化漏斗图 | FunnelChart | 5 阶段漏斗 + 转化率标注 |
| 13 | 用户增长趋势图 | LineChart | 新增用户数折线 |
| 14 | 时间维度切换(用户分析) | ButtonGroup | 日/周/月 |

### ④ 交互说明

| 触发 | 行为 |
|------|------|
| 时间筛选切换 | 页面所有模块（指标卡片+环比+全部图表）同步刷新 |
| 环比基准切换 | 12 个指标卡片的环比值同步刷新 |
| 财务趋势-维度切换 | 仅财务趋势图刷新 |
| 订单趋势-维度切换 | 仅订单趋势图刷新 |
| 品项贡献-TOP 切换 | 条形图更新展示数量 |
| 品项名称点击(P1) | 弹窗展示该品项近30天销售趋势(销量+销售额双线折线图) |
| 漏斗图阶段点击(P1) | 跳转对应状态订单列表 |
| 指标卡片点击(P1) | 跳转对应明细页面 |
| 图表 hover | tooltip 显示具体数值 |

### ⑤ 状态说明

| 状态 | 表现 |
|------|------|
| Loading | 指标卡片骨架屏 + 图表区 spinner |
| 正常 | 全部数据正常展示 |
| 空数据 | 新平台无数据：卡片显示 0，环比显示 "--"，图表显示"暂无数据" |
| 部分指标失败 | 失败指标显示 "--"，其他正常展示 |
| 图表加载失败 | 对应图表区显示"加载失败" + 重试按钮 |
| 无权限 | "您没有访问经营看板的权限" |

| 状态 | 表现 |

| 加载失败 | "加载失败" + 重试按钮 |
