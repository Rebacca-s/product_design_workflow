# 需求分析与范围定义 — 经营看板 & 财务管理

## 1. 用户角色

| 角色 | 描述 | 使用模块 | 权限建议 |
|------|------|----------|----------|
| 老板 | 平台所有者 | 经营看板 + 财务管理 | 全部数据可见 |
| 运营人员 | 负责日常运营 | 经营看板 | 经营看板可见，财务管理不可见 |
| 财务人员 | 负责对账结算 | 财务管理 | 财务管理可见，经营看板不可见 |
| 管理人员 | 高层管理 | 经营看板 + 财务管理 | 全部数据可见 |

> **【当前假设】** 权限按菜单级别控制：有经营看板权限 → 可见经营看板菜单；有财务管理权限 → 可见财务管理菜单。

## 2. 使用场景

| 编号 | 场景 | 角色 | 频率 |
|------|------|------|------|
| S1 | 每天上午查看昨日经营数据（GMV/订单/用户增长）及环比变化 | 老板/运营 | 每日 |
| S2 | 查看本周收入结构和品项贡献，评估活动效果和品类表现 | 运营 | 每周 |
| S3 | 监控商品订单与体检订单的转化漏斗，定位流失环节 | 运营 | 每周 |
| S4 | 监控体检订单履约状态（待寄样积压情况） | 运营 | 每日 |
| S5 | 查看收入/退款/服务商提成支出，核对资金数据 | 财务 | 每日 |
| S6 | 导出月度财务报表用于税务申报 | 财务 | 每月 |
| S7 | 追溯某笔订单的完整资金流水 | 财务 | 按需 |

## 3. 功能范围

### P0 — 本期必须完成

**经营分析（一级菜单）> 经营看板**：
| 编号 | 功能 | 说明 |
|------|------|------|
| B1 | 核心经营指标 | 12个指标卡片 + 环比增长率（支持较昨日/较上周/较上月切换）+ 时间筛选 |
| B2 | 财务趋势 | 三线折线图（商品收入/体检收入/总收入），支持日/周/月切换 |
| B3 | 订单趋势 | 三线折线图（商品订单数量/体检订单数量/总订单数量），支持日/周/月切换 |
| B4 | 收入结构分析 | 环形图，展示商品收入 vs 体检收入占比 |
| B5 | 品项贡献分析 | 横向条形图，TOP5/10/20 可切换，按销售金额降序，展示贡献率 |
| B6 | 体检业务分析 | 漏斗图，展示体检订单转化（待付款→待寄出取样器→已收货待检验→检验中→已完成） |
| B7 | 商品订单转化漏斗 | 漏斗图，展示商品订单转化（待付款→待发货→待收货→待评价→已完成） |
| B8 | 用户分析 | 折线图，展示用户增长趋势，支持日/周/月切换 |
| B9 | 订单生命周期 | 商品/体检订单详情弹窗中增加时间轴，展示订单状态流转+变更时间 |

**经营分析（一级菜单）> 品项销售**：
| 编号 | 功能 | 说明 |
|------|------|------|
| S1 | 商品销售 | 筛选(商品名称/分类/时间) + 列表(9字段) + 排序 + 导出 |
| S2 | 体检销售 | 筛选(套餐名称/体检类型/时间) + 列表(9字段) + 排序 + 导出 |

> 品项销售通过 Tab 切换「商品」和「体检」两个视图。

**财务管理（一级菜单，3 个二级路由）**：
| 编号 | 功能 | 说明 |
|------|------|------|
| F0 | 资金概况 | 账面余额/待退款/待结算/可用资金指标卡 + 资金趋势图 + 占用饼图 + 快捷入口 |
| F1 | 财务概览 | 收入/退款/已结算支出(供货商货款/门店货款/KA提成/Pro提成)/实际收入/利润指标卡(4档) + 趋势图 + 财务明细报表(按日/月 + 导出Excel) |
| F2 | 财务流水 | 列表+筛选(时间/类型/业务类型/订单号)+导出 |
| F4 | 供货商成本 | 利润 = 实际收入 - KA服务商提成 - Pro服务商提成 - 供货商货款 - 门店货款；供货商货款支出 / 门店货款支出 / KA服务商提成支出 / Pro服务商提成支出纳入财务流水（供货商管理独立设计，见 outputs/合作管理/） |

> 财务管理不再使用 Tab 切换，改为 3 个独立二级路由页面。原「财务报表」已并入「财务概览」，作为其底部的「财务明细报表」区块（含按日/月明细表格 + 导出 Excel）。
