# 需求分析与范围定义 — 录音笔记组件

> 简化版（小迭代）

## 1. 用户故事

| 项目 | 内容 |
|------|------|
| 作为 | 使用员工对话功能的员工 |
| 我想要 | 在对话前选择录音笔记中的知识库/文件，将其总结内容作为对话上下文 |
| 以便于 | 基于已有的录音记录内容进行 AI 问答和分析，提升录音内容的利用效率 |

## 2. P0 功能范围

| 编号 | 功能 | 说明 | 端 |
|------|------|------|------|
| F1 | 录音笔记组件入口 | 员工对话页组件区新增「录音笔记」按钮 | PC 员工端 |
| F2 | 知识库选择弹窗 | 弹窗展示员工有权限的知识库列表，支持多选/单选 + 文件选择，默认全选 | PC 员工端 |
| F3 | 对话上下文注入 | 选择确认后，将知识库/文件的录音总结内容作为 AI 对话上下文 | PC 员工端 |
| F4 | 后台组件类型新增 | 后台"添加组件"中新增「录音笔记组件」类型 | 后台管理 |
| F5 | 员工组件配置 | 新增/编辑员工时可勾选录音笔记组件 | 后台管理 |

## 3. 本期不包含

| 编号 | 内容 | 原因 |
|------|------|------|
| N1 | 录音笔记知识库的创建和管理 | 属于已有录音笔记模块功能，本次不涉及 |
| N2 | 录音总结内容的生成 | 由已有录音笔记模块负责，本次仅读取使用 |
| N3 | 对话上下文的其他内容类型接入 | 本次仅接入录音笔记，未来其他内容类型另行评估 |
| N4 | 移动端适配 | 需求明确限定 PC 端 |
| N5 | 原始录音音频播放 | 需求明确使用总结文本内容 |

## 4. 依赖

| 依赖项 | 说明 | 风险 |
|--------|------|------|
| 录音笔记知识库接口 | 需提供知识库列表、文件列表、录音总结内容读取接口 | 中——接口如不可用需协调开发 |
| 录音笔记权限体系 | 需提供员工对知识库的权限数据 | 低——已有权限体系 |
| 对话组件扩展机制 | 需支持新增组件类型的注册和渲染 | 低——已有组件体系 |
| 后台组件管理功能 | 需支持新增组件类型选项 | 低——已有组件管理功能 |

## 5. 关键交互规则（用户确认）

| 规则 | 说明 |
|------|------|
| 知识库权限 | 员工在弹窗中看到的范围 = 该员工在录音笔记中可访问的知识库范围 |
| 默认选择 | 弹窗默认全选所有有权限的知识库 + 全部文件 |
| 0 个知识库 | 允许不选择任何知识库，确认后不携带录音内容上下文，直接进行常规 AI 对话 |
| 选择持久化 | 每次新建对话时继承上次选择的知识库/文件配置 |
| 触底加载 | 知识库列表和文件列表采用触底加载（滚动到底部自动加载更多），不分页 |
| 样式切换 | 弹窗根据选择数量动态切换：0/全部/N个(N>1)→仅知识库列表（样式A）；1个知识库→展开该库文件列表（样式B） |
| 多选支持 | 支持同时选择多个知识库，默认全选 |
| 提示文案 | 全部知识库→"全部知识库 · 全部文件"；N个→"N个知识库 · 全部文件"；1个+全选文件→"[名称] · 全部文件"；1个+N文件→"[名称] · N个文件"；0个→"不选择知识库" |
