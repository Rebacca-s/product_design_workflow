# HTML 原型生成提示词 — 录音笔记组件

> 可直接复制到 Cursor / Claude 使用

---

## 产品背景

元梦客是一款 PC 端 AI 员工对话产品。员工可在对话页与 AI 进行业务问答。对话框上方有组件区域，已支持「新话题」「上传文件」等对话组件。应用中心已有「录音笔记」功能，员工可录制并管理业务录音，系统自动生成录音总结文本。

本次需要在员工对话组件区新增「录音笔记组件」，让员工在对话前选择录音笔记知识库/文件，将录音总结内容作为 AI 对话上下文。

## 页面范围

仅生成 **PC 端员工对话页** 中的以下部分：

1. **组件区新增「录音笔记」按钮**（默认态 + 已选中态）
2. **知识库选择弹窗**（模态弹窗，含两种样式切换）
   - 样式A（多库模式）：显示知识库列表，支持多选
   - 样式B（单库模式）：显示知识库列表 + 展开单个知识库的文件列表

## 设计风格

- PC 端 Web 页面，适配 1440px 宽度
- 简洁专业的 SaaS 风格
- 使用中性色调，按钮使用品牌蓝色作为主色
- 弹窗使用白色背景 + 阴影 + 圆角
- 已有组件按钮使用标签/胶囊风格
- 录音笔记按钮选中态使用高亮边框或浅蓝底色 + 数量角标

## 交互要求

### 录音笔记按钮
- **默认态**：标签样式，图标 + "录音笔记" 文字，与其他组件按钮排列在同一行
- **已选中态（全部知识库）**：蓝色高亮 + "录音笔记 · 全部知识库"
- **已选中态（N个知识库）**：蓝色高亮 + "录音笔记 · N个知识库"
- **已选中态（1个知识库）**：蓝色高亮 + "录音笔记 · [知识库名称]"
- **已选中态（1个知识库+N文件）**：蓝色高亮 + "录音笔记 · [知识库名称] · N个文件"
- **已选中态（0个知识库）**：蓝色高亮 + "录音笔记"（无角标）
- 点击按钮 → 弹出知识库选择弹窗

### 知识库选择弹窗
- **弹出动画**：从按钮位置缩放弹出，背景半透明遮罩
- **加载状态**：先展示骨架屏/Skeleton，1 秒后加载完成
- **搜索功能**：顶部搜索框，输入关键词实时过滤知识库列表
- **全选功能**：顶部「全选」复选框，一键全选/取消
- **知识库列表**：每项显示 ☑ 复选框 + 知识库名称 + 文件数量角标；列表项较多时采用触底加载（滚动到底部自动追加更多数据）
- **样式A（多库/全库/零库模式）**：仅显示知识库列表（勾选0/全部/N个知识库，N≠1）
  - 0个：底部提示"不选择知识库"
  - 全部：底部提示"全部知识库 · 全部文件"
  - N个(N>1)：底部提示"N个知识库 · 全部文件"
- **样式B（单库模式）**：仅勾选 1 个知识库时自动切换 — 在该知识库下方展开文件列表（带"全选文件"复选框，触底加载）
  - 全选文件：底部提示"[知识库名称] · 全部文件"
  - N个文件：底部提示"[知识库名称] · N个文件"
- **确认按钮**：始终可用，0 个知识库时确认 = 不注入录音上下文，直接进入常规 AI 对话
- **取消/关闭**：点击取消按钮或遮罩层 = 恢复到上次选择并关闭

### 边界情况
- 空状态：无可用知识库时显示"暂无可用知识库"空状态，底部提示"不选择知识库"，确认按钮仍可用
- 搜索无结果：显示"未找到匹配的知识库"

## 数据要求

使用真实感中文模拟数据：

**知识库列表**：
- 客户沟通记录 (12个文件)
- 内部会议纪要 (8个文件)
- 产品需求讨论 (5个文件)
- 项目周报汇总 (20个文件)
- 培训与分享 (3个文件)

**文件列表（以"客户沟通记录"为例）**：
- 2026-07-25 客户A项目需求沟通
- 2026-07-23 客户B方案演示反馈
- 2026-07-20 客户C售后问题跟进
- 2026-07-18 客户D合同条款讨论
- 2026-07-15 客户E产品试用反馈

## 技术提示
- 使用纯 HTML + CSS + JS 实现
- 不需要框架
- 弹窗使用 fixed 定位 + 遮罩层
- 样式切换使用 JS 监听复选框变化
- 搜索使用简单的字符串匹配过滤
- 状态管理使用 JS 对象存储当前选择
- 列表触底加载：监听 scroll 事件，触底时追加数据（模拟分页加载）
- 底部提示文案根据选择的知识库数量动态更新
