# 原型说明文档 — 录音笔记组件

## 1. 页面清单

| 编号 | 页面名称 | 端 | 类型 | 优先级 |
|------|----------|------|------|--------|
| P1 | 员工对话页（含录音笔记组件+弹窗） | PC 员工端 | 改动页 | P0 |
| P2 | 后台-组件管理页 | PC 后台 | 改动页 | P0 |
| P3 | 后台-员工管理页（新增/编辑表单） | PC 后台 | 改动页 | P0 |

## 2. 页面跳转关系

```
后台：
  组件管理 → 添加组件（含录音笔记类型）
  员工管理 → 新增/编辑员工（含组件勾选）

PC 员工端：
  员工对话页 → 点击录音笔记按钮 → 知识库选择弹窗（模态）
```

## 3. P1 - 员工对话页 设计说明

### 3.1 页面目标
在现有员工对话页组件区新增录音笔记入口，让员工快速选择知识库后将录音内容注入对话。

### 3.2 页面结构
详见 PRD A6 章节 ASCII Wireframe。

### 3.3 信息层级
1. 顶部导航栏：返回 + 页面标题 + 设置
2. 组件区：已有组件 + 新增录音笔记按钮
3. 对话消息区：AI 对话内容
4. 输入区：输入框 + 发送按钮
5. 知识库选择弹窗（模态层）

### 3.4 关键组件

| 组件 | 说明 |
|------|------|
| 录音笔记按钮 | 组件区新增按钮；默认态/已选中态两种样式 |
| 知识库选择弹窗 | 模态弹窗；左右双栏布局（左=KB列表+转换状态图标，右=文件列表），含搜索、全选、确认取消 |
| Toast | 操作结果提示 |

### 3.5 按钮设计

| 按钮 | 位置 | 样式 | 行为 |
|------|------|------|------|
| 录音笔记（默认态） | 组件区 | 图标+文字，与其他组件风格一致 | 打开弹窗 |
| 录音笔记（已选中） | 组件区 | 高亮/选中样式 + 选择摘要角标（如"全部知识库"、"3个知识库"、"知识库A"） | 打开弹窗（回显） |
| 确认选择 | 弹窗底部 | 主按钮，始终可用 | 保存选择，关闭弹窗 |
| 取消 | 弹窗底部 | 次按钮 | 恢复上次选择，关闭弹窗 |

### 3.6 5 种状态

| 状态 | 触发 | 表现 |
|------|------|------|
| 默认态 | 首次使用/未选择 | 按钮默认样式 |
| 已选中态（有知识库） | 已确认选择 | 按钮高亮 + 选择摘要角标 |
| 已选中态（0个知识库） | 已确认选择0个 | 按钮高亮 + "录音笔记"（无角标） |
| 弹窗-加载中 | 请求知识库列表 | Loading 动画 |
| 弹窗-空 | 无权限知识库 | 空状态插图 + 文案"暂无可用知识库"，可确认 |
| 弹窗-异常 | 接口失败 | 错误提示 + 重试按钮 |

### 3.7 交互细节

- 弹窗打开动画：从按钮位置缩放入场
- 样式A↔B 切换：勾选/取消勾选知识库时即时切换（0/全部/N个→样式A；1个→样式B）
- 搜索：实时过滤，200ms 防抖
- 触底加载：知识库列表和文件列表滚动到底部自动加载更多
- 确认后（有选择）：弹窗关闭 + 按钮切换选中态 + Toast"已更新录音笔记上下文"
- 确认后（0个知识库）：弹窗关闭 + 按钮切换选中态（无角标），不注入上下文
- 点击弹窗外部遮罩：等于点击取消
