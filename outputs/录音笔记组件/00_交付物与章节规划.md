# 交付物与章节规划 — 录音笔记组件（含知识库转换与RAG检索）

## 1. 原始需求

### 模块一（v0.1）
> 元梦梦客 PC 端员工对话新增「录音笔记组件」——将已有录音笔记知识库能力接入员工对话组件，支持选择知识库/文件，携带录音总结内容作为 AI 对话上下文。后台新增组件类型和员工配置。

### 模块二（v0.2）【新增】
> 录音笔记知识库转换为正式向量化知识库，支持 RAG 检索。员工对话组件从"全文注入"升级为"知识库范围选择 + 动态向量检索"。支持跨知识库组合选择。

## 2. 需求类型判断

| 维度 | 判断 |
|------|------|
| 产品类型 | PC Web（员工对话端 + 后台管理端） |
| 目标用户 | 员工（对话使用者）、管理员（后台配置者） |
| 核心场景 | 员工对话前选择录音笔记知识库，基于录音内容进行 AI 对话 |
| AI 产品 | 部分（对话上下文注入涉及已有 AI 对话，但不新增 AI 能力） |
| 需要后台 | 是 |
| 终端形态 | PC 端 Web + 后台管理 |

| 需求类型 | 是否命中 | 判断依据 |
|----------|----------|----------|
| 新产品需求 | 否 | 非新产品 |
| 大功能需求 | 否 | 范围明确，复用已有机制 |
| **小迭代需求** | **是** | 在已有组件体系上新增一个组件类型 |
| AI 功能需求 | 否 | 不引入新 AI 能力，将已有内容作为已有 AI 对话上下文 |
| **非 AI 功能需求** | **是** | 核心是组件接入 + 内容选择器 + 后台配置 |
| **后台管理功能需求** | **是** | 涉及组件类型管理和员工配置 |
| 页面改版需求 | 否 | 非改版 |
| 数据统计/埋点需求 | 否 | 未涉及 |
| 权限/角色需求 | 否 | 权限与已有录音笔记一致 |
| 状态流转类需求 | 否 | 不涉及 |

**综合判断**：小迭代需求 + 后台管理功能需求 + 非 AI 功能需求
