# PRD 产品需求文档 — 评价与售后规则优化

> 小迭代简化版。本次为现有订单评价和售后体系的规则补全。

---

## A1-A4（合并）. 需求概述

### 业务现状

- 商品订单（快递+自提）和体检订单（寄样+到店）均已有"待评价"状态
- 分销体系中，用户支付后佣金进入"冻结中"，需等待冻结天数过后进入"可结算"
- 待评价状态下有"申请售后"按钮，目前**无时间限制**

### 本期问题


| 问题                   | 影响             |
| -------------------- | -------------- |
| 用户评价后，订单详情看不到自己的评价内容 | 用户无法回顾评价，体验差   |
| 无评价有效期和默认好评          | 已完成的订单没有评价数据沉淀 |
| 分销冻结→可结算的时机规则模糊      | 服务商不清楚何时能结算    |
| 待评价下售后无时效            | 可能已收货很久后仍申请售后  |


### 本期目标

1. 订单详情展示已提交的评价
2. 评价有效期7天 + 超时默认5星好评
3. 明确分销冻结→可结算链路
4. 待评价售后申请时效7天

---

## A5. 功能说明

### F1. 订单详情展示已评价内容

**现状**：用户评价提交后，进入该订单详情看不到自己的评价。

**改后**：已评价订单的详情页底部新增"我的评价"区块。


| 规则项    | 说明                               |
| ------ | -------------------------------- |
| 展示条件   | 该订单已提交评价（无论订单当前状态是待评价还是已完成）      |
| 展示位置   | 订单详情页底部，订单信息下方                   |
| 展示内容   | 评分星级 + 评价文字 + 评价图片（可点击放大） + 评价时间 |
| 适用订单类型 | 商品订单（快递+自提）+ 体检订单（寄样+到店）         |
| 不展示条件  | 订单未评价；订单已过期/已取消/已退款              |


---

### F2. 评价有效期 + 默认好评


| 规则项    | 说明                                    |
| ------ | ------------------------------------- |
| 评价有效期  | 进入"待评价"状态后 **7天**                     |
| 有效期起点  | 订单状态变为"待评价"的时间点                       |
| 有效期内   | "评价"按钮正常展示，点击进入评价表单                   |
| 超期未评价  | 系统自动执行：评分5星 + 评价内容"系统默认好评" + 订单状态→已完成 |
| 超期已评价  | 不受影响，正常流转                             |
| 自动评价执行 | 系统定时任务，每天扫描"待评价"且超过7天的订单              |


**状态流转**：

```
进入"待评价" 
    ├── 7天内用户评价 → 订单→已完成
    └── 7天超期未评价 → 系统自动5星好评 → 订单→已完成
```

**时效计算示例**：

- 7月1日 10:00 进入待评价 → 7月8日 10:00 超期
- 超期后第二天定时任务执行默认好评

---

### F3. 分销结算链路明确

**现状**：用户支付 → 佣金"冻结中" → 订单待评价 → 冻结天数过后 → "可结算"。但规则没有在PRD中写清楚。

**本次明确**：

```
用户支付成功
    ↓
服务商佣金 → 状态："冻结中"
    ↓
订单经历：待发货→待收货→待评价（或门店自提：待使用→待评价）
    ↓                                            ↓
（整个过程中佣金保持"冻结中"）                   用户申请售后退款 → 冻结顺延，不结算
    ↓
订单进入"待评价" + 冻结天数已过（分销设置中的冻结天数）
    ↓
佣金状态 → "可结算"
    ↓
服务商可提现
```


| 规则     | 说明                          |
| ------ | --------------------------- |
| 冻结起点   | 用户支付成功                      |
| 冻结终点   | 订单进入"待评价" + 冻结天数已过（两个条件都满足） |
| 售后影响   | 订单有未完结的售后单时，不结算（冻结顺延）       |
| 与评价解耦  | 用户是否评价不影响结算，只取决于状态+天数       |
| 默认好评影响 | 超时默认好评后订单进入已完成，不影响冻结天数计时    |


---

### F4. 售后申请时效限制

**现状**：待评价状态下"申请售后"按钮无时间限制。

**改后**：待评价状态下申请售后有时效窗口。


| 规则项      | 说明                  |
| -------- | ------------------- |
| 售后时效     | 进入"待评价"状态后 **7天**   |
| 时效起点     | 订单变为"待评价"的时间        |
| 时效内      | "申请售后"按钮正常，点击进入售后流程 |
| 超时后      | 按钮仍展示，但点击弹出提示弹窗     |
| 是否影响其他状态 | 否，仅限制"待评价"状态下的售后申请  |


**超时弹窗内容**：

```
┌──────────────────────────────┐
│      超过申请时效             │
│                              │
│  售后申请有效期为确认收货后    │
│  7天内，您的订单已超过申请     │
│  时效。如需帮助，请联系商家。  │
│                              │
│   联系电话：010-12345678      │  ← 有门店→门店电话；无门店→平台客服电话
│                              │
│        [ 知道了 ]            │
└──────────────────────────────┘
```

**联系电话逻辑**：


| 订单类型          | 联系电话来源           |
| ------------- | ---------------- |
| 门店自提 / 线下门店预约 | 订单关联**门店的联系电话**  |
| 快递配送 / 线上寄样   | **平台客服电话**（固定配置） |


**不同状态下的售后按钮行为**：


| 订单状态        | 售后按钮       | 点击行为     |
| ----------- | ---------- | -------- |
| 待发货/待使用     | 可申请        | 正常进入售后流程 |
| 待收货         | 可申请        | 正常进入售后流程 |
| 待评价（7天内）    | 可申请        | 正常进入售后流程 |
| 待评价（超7天）    | 可申请（展示但受限） | 弹出超时提示弹窗 |
| 已完成         | 可申请        | 正常进入售后流程 |
| 已过期/已取消/已退款 | 不展示        | —        |

## A8. 异常情况


| 异常            | 触发条件       | 处理                             | 提示             |
| ------------- | ---------- | ------------------------------ | -------------- |
| 售后超时          | 待评价超7天点击售后 | 弹出超时弹窗，不进入售后                   | "超过申请时效，请联系商家" |
| 自动评价失败        | 定时异常任务执行   | 记录日志，下次扫描重试                    | 无用户提示（后端处理）    |
| 订单同时触发自动评价和售后 | 边缘情况       | 先执行到的不重复执行；自动评价后订单变已完成，售后自然不可用 | —              |
| 售后中订单超7天      | 售后流程进行中    | 不受售后时效限制，售后流程正常继续              | —              |


---

## A9. 验收标准

- [ ] 已评价订单详情页展示"我的评价"区块，含评分、文字、图片、时间
- [ ] 未评价订单详情页不展示"我的评价"区块
- [ ] 待评价状态超过7天，系统自动执行5星默认好评，订单进入已完成
- [ ] 分销佣金：支付后冻结中 → 待评价+冻结天数过后 → 可结算
- [ ] 待评价7天内点击"申请售后"正常进入售后流程
- [ ] 待评价超7天点击"申请售后"弹出超时提示弹窗，可查看商家电话
