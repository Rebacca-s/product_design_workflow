# 交付物与章节规划 — 评价与售后规则优化

## 1. 原始需求

1. 订单详情展示用户已提交的评价内容（商品+体检，目前评价后看不到自己的评价）
2. 评价有效期 + 默认好评：进入"待评价"后7天内可评价，超期系统自动5星好评
3. 分销结算链路明确：支付→冻结中→待评价→冻结天数后→可结算
4. 售后申请时效：待评价状态下申请售后有时效限制，7天内可申请，超时提示联系商家

## 2. 需求类型判断

| 需求类型 | 命中 | 依据 |
|----------|------|------|
| 小迭代需求 | 是 | 4个关联需求，改动在订单详情+评价规则 |
| 非AI功能 | 是 | 纯业务规则 |
| 状态流转类 | 是 | 分销冻结→可结算、评价超时自动完成 |
