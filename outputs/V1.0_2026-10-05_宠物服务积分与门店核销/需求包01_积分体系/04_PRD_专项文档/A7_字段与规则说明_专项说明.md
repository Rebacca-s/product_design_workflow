# A7 字段与规则说明 — 积分体系

## 一、核心字段表

### 1. 积分账户

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| 用户 ID | string | 是 | 关联用户唯一标识 | U10001 |
| 可用积分 | int | 是 | 当前可消费积分 | 8000 |
| 累计获得 | int | 是 | 历史累计增加 | 12000 |
| 累计消耗 | int | 是 | 历史累计减少 | 4000 |
| 即将到期积分 | int | 否 | 未来 N 天内将到期的积分（用于提醒展示） | 500 |
| 更新时间 | datetime | 是 | 最后变动时间 | 2026-10-05 12:00 |

### 2. 积分流水

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| 流水 ID | string | 是 | 唯一标识 | L1001 |
| 用户 ID | string | 是 | 关联用户 | U10001 |
| 变动类型 | enum | 是 | 获得/消耗/调整/退还/过期 | 消耗 |
| 变动值 | int | 是 | 正数为增，负数为减 | -8000 |
| 变动后余额 | int | 是 | 本次变动后余额 | 0 |
| 到期时间 | datetime | 否 | 「获得」类型流水的积分到期时间 | 2027-10-05 |
| 来源/原因 | string | 是 | 业务来源或人工原因 | 兑换订单 SO1001 |
| 关联业务 | string | 否 | 订单号/活动 ID | SO1001 |
| 操作人 | string | 否 | 人工调整时的后台操作人 | admin_zhang |
| 变动时间 | datetime | 是 | 时间戳 | 2026-10-05 12:00 |

### 3. 商品积分配置

| 字段名 | 类型 | 必填 | 说明 | 默认 |
|--------|------|------|------|------|
| 商品 ID | string | 是 | 关联商品 | — |
| 是否支持积分支付 | bool | 是 | 是/否 | 否 |
| 是否赠送积分 | bool | 是（预留） | 是/否 | 否 |
| 赠送比例 | int | 否 | 待确认 | 0 |

### 4. 系统参数

| 字段名 | 类型 | 必填 | 说明 | 当前值 |
|--------|------|------|------|--------|
| 积分兑换比例 | int | 是 | 1 元 = N 积分 | 10 |
| 积分统一有效期 | int | 是 | 积分入账后有效月数（可配置） | 12 |

## 二、校验规则

| 规则 | 说明 |
|------|------|
| 积分数量 | 正整数，不允许 0 或负数 |
| 余额校验 | 扣减/抵扣时可用积分不足则拦截 |
| 原因必填 | 人工调整必须填写原因 |
| 互斥校验 | 积分抵扣与优惠券互斥，结算侧强校验 |
| 幂等 | 同一订单同一积分抵扣请求只扣一次 |
| 比例生效 | 兑换比例修改仅影响后续订单（需研发确认） |

## 三、字段规则结论与待确认

- 积分有效期字段：【已确认】统一有效期，流水记录「到期时间」，系统参数配置有效月数。
- 积分类型（人工 vs 消费赠送）：【已确认】不分池，仅用「变动类型」字段区分。
- 退款返还字段：【已确认】退款产生「退还」类型流水，积分原路退回。
- 待确认：退款返还积分的到期时间计算方式（按原到期时间退回 vs 重新起算）。
