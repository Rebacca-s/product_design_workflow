# B3 状态流转 — 积分体系

## 一、积分流水状态（类型维度）

| 类型 | 触发条件 | 变动方向 |
|------|----------|----------|
| 获得 | 后台人工发放 / 未来消费赠送 | + |
| 消耗 | 兑换抵扣成功 | - |
| 调整 | 后台人工扣减（纠错） | - |
| 退还 | 积分订单退款，积分原路退回账户 | + |
| 过期 | 积分到期自动作废 | - |

> 流水为不可变追加记录，不产生状态回退；如需纠错通过新增反向「调整」流水完成。

## 二、积分抵扣订单状态流转

```
下单（选择积分抵扣）
    ↓
待支付 ──取消/超时──> 已取消（释放占用积分）
    ↓ 支付成功
已支付（积分已实际扣减）
    ↓ 退款
已退款（积分原路退回账户）
```

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| 待支付 | 已锁定积分，未支付 | 支付 / 取消 |
| 已支付 | 积分已扣减 | 申请退款 |
| 已取消 | 释放锁定积分 | — |
| 已退款 | 退款完成，积分原路退回 | — |

## 三、状态流转规则

- 订单取消/超时未支付 → 释放锁定的积分，不产生「消耗」流水。
- 支付成功 → 产生「消耗」流水。
- 退款 → 积分原路退回账户，产生「退还」类型流水。【已确认】
