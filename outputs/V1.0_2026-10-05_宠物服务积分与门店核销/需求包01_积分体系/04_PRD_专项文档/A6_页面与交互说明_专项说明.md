## 三、页面元素说明（以 P4 结算页为例）

| 元素 | 类型 | 说明 |
|------|------|------|
| 支付方式选择 | Radio | 全积分 / 积分+现金 / 现金 |
| 积分输入框 | Input(number) | 积分+现金模式显示 |
| 抵扣金额 | Text | 实时计算 积分÷比例 |
| 优惠券入口 | Button | 勾选积分后禁用 |
| 实付金额 | Text | 现金部分 |
| 提交订单 | Button | 触发支付 |

## 四、交互规则

- 勾选「全积分」：若积分充足可提交，不足提示并切换「积分+现金」。
- 勾选「积分+现金」：显示积分输入框，实时显示抵扣与现金金额。
- 勾选「使用积分」后，优惠券入口禁用；勾选优惠券后积分抵扣禁用（互斥）。
- 会员价：结算页自动按用户实际享受价展示与计算。
- 积分扣减：系统自动优先使用快过期积分（先进先出）。

## 五、页面状态

| 状态 | 表现 |
|------|------|
| 首次进入 | 加载账户积分与商品价格 |
| Loading | 骨架屏 |
| 正常 | 完整展示 |
| 空状态 | 积分为 0 时「暂无可用积分」 |
| 积分不足 | 全积分置灰/提示 |
| 异常 | 网络错误提示重试 |
| 成功 | 支付成功跳转订单详情 |
