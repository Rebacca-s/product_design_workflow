# HTML 原型生成提示词 — 积分体系

> 可直接复制给 Cursor / Claude 生成可交互 HTML 原型（移动端优先）。

---

请生成一个移动端 H5 原型，主题为「宠物服务平台 — 积分体系」，包含以下页面，移动端宽度优先（375px），视觉有质感、圆角卡片、柔和宠物风格配色（暖橙+白+浅灰），使用真实中文内容。

## 产品背景

宠物服务平台，用户线下到合作宠物医院消费后，医院返点、平台以积分形式返还用户，用户用积分在平台商城兑换商品/服务。兑换比例 1 元 = 10 积分。会员价可与积分共用，积分与优惠券互斥。

## 页面范围

1. **积分中心**：顶部可用积分大数字，累计获得/累计消耗，两个按钮「去兑换」「积分明细」，下方兑换推荐商品卡片。
2. **积分明细**：积分流水列表，每项显示变动类型（获得/消耗）、数量（+/-）、时间、来源；顶部类型筛选。
3. **积分兑换列表**：支持积分支付的商品列表，每项显示商品图、名称、价格、所需积分。
4. **结算页**：商品信息、原价/会员价、支付方式单选（全积分支付 / 积分+现金 / 现金支付）、积分输入框实时换算抵扣与现金金额、优惠券入口（勾选积分后禁用）、实付金额、提交订单按钮。

## 交互要求

- 结算页「积分+现金」选中后显示积分输入框，实时计算「抵扣金额 = 积分 ÷ 10」与「现金应付」。
- 勾选任意积分支付方式后，优惠券入口置灰并提示「积分与优惠券不可同时使用」。
- 全积分支付时若积分不足，按钮置灰并提示「积分不足」。
- 页面间可点击跳转（积分中心 ↔ 明细 ↔ 兑换列表 → 结算）。
- 积分数值、商品均用真实中文内容（如：宠物体检套餐 ¥800 / 8000 积分）。

## 输出要求

单文件 HTML（内联 CSS/JS），可直接浏览器打开，有基础点击与状态切换交互。
