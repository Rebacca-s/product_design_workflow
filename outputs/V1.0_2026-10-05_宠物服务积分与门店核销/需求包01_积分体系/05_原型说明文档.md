# 原型说明文档 — 积分体系

## 1. 页面清单与跳转关系

```
用户端：
  我的 → 积分中心(P1)
         ├── 积分明细(P2)
         └── 去兑换 → 积分兑换列表(P3) → 商品详情 → 结算页(P4)
  结算页(P4) 内嵌积分抵扣模块

后台：
  积分管理
   ├── 用户账户(P5) → 人工调整积分(P6)
   └── 积分流水(P7)
  商品管理 → 商品编辑 → 积分设置(P8)
```

## 2. 设计目标

- 用户端：积分价值直观、抵扣操作简单、优惠互斥规则清晰。
- 后台：发放高效、可追溯、防误操作。

## 3. 页面设计说明（摘要）

每页完整结构见 `04_PRD_专项文档/A6_页面与交互说明_专项说明.md`。核心页面要点：

- **P1 积分中心**：顶部展示可用积分大数字，次级累计获得/消耗，两个主操作「去兑换」「积分明细」。
- **P4 结算页**：支付方式 Radio 三选（全积分/积分+现金/现金），积分输入实时换算，优惠券入口在勾选积分后禁用。
- **P6 人工调整**：搜索用户 → 单选增/减 → 数量 → 必填原因 → 二次确认。

## 4. 关键交互

- 会员价作为抵扣基准（自动）。
- 积分与优惠券互斥（联动禁用）。
- 全积分不足自动提示切换。

## 5. 状态覆盖

首次进入 / Loading / 正常 / 空状态 / 积分不足 / 异常 / 成功 七态均已定义（见专项）。
