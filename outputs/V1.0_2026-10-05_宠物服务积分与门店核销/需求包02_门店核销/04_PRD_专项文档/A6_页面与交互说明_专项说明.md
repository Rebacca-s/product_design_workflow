## 一、页面清单与跳转关系

| 编号 | 页面 | 端 | 入口 |

| P1 | 核销凭证页 | 用户端 | 订单详情 / 我的-核销凭证 |
| P2 | 门店登录页 | 门店小程序 | 打开小程序 |

## 三、页面元素说明（以 P4 为例）

| 元素 | 类型 | 说明 |
|------|------|------|
| 用户 | Text | 脱敏展示 |
| 商品 | Text | 商品名 |
| 订单 | Text | 订单号 |
| 凭证原门店 | Text | 跨店核销时展示；实际核销门店 ≠ 凭证原门店时显著标识 |
| 状态 | Tag | 待使用 |
| 确认核销 | Button | 触发核销 |

## 四、交互规则

- 扫码成功 → 校验（含连锁主体匹配）→ 跳转 P4 展示待核销信息；确认后 → P5 结果页。
- 扫码失败/无效码 → 提示对应异常（见 A8）。
- 手动输码 → 走与扫码相同校验流程。
- 跨店核销：同连锁主体门店可核销，P4 展示「凭证原门店」，核销记录记录「实际核销门店」。
- 门店登录：后台预建账号，登录后识别所属门店及连锁主体。

## 五、页面状态

| 状态 | 表现 |
|------|------|
| 首次进入 | 门店登录 |
| Loading | 扫码解析中 |
| 正常 | 展示待核销信息 |
| 空状态 | 无待核销凭证 |
| 已核销 | 结果页提示已核销 |
| 异常 | 无效码/非本连锁门店/订单异常提示 |
| 成功 | 核销成功 |
