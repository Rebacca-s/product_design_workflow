# B3 状态流转 — 门店核销

## 一、核销凭证状态机

```
订单支付成功
    ↓
[待使用]
    ├── 门店核销成功 → [已核销]（终态）
    ├── 订单退款/取消 → [已退款/已取消]（终态，不可核销）
    └── 过期/作废 → [已失效]（终态，规则待确认）
```

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| 待使用 | 已支付，未核销 | 核销 |
| 已核销 | 已完成核销 | 无 |
| 已失效 | 过期/作废 | 无 |
| 已退款/已取消 | 订单退款/取消 | 无（不可核销） |

## 二、状态流转规则

- 仅「待使用」可流转到「已核销」。
- 退款/取消后凭证立即失效，不可核销。
- 已核销/已失效/已退款均为终态，不可回退（撤销待确认）。

## 三、状态启用范围（当前假设）

- **「已失效」态**：因「核销码有效期」规则【待确认】（第 13 项），本期暂不启用该状态。当前实际生效状态仅三态：待使用 / 已核销 / 已退款·已取消。待有效期规则确定后再启用「已失效」，研发需预留该枚举值但默认不触发。

## 四、待确认

- 核销码有效期导致「已失效」的具体规则（第 13 项）。
- 核销错误是否可撤销（第 19 项，当前假设：暂不支持撤销）。
- 是否需后台人工核销兜底（第 20 项，当前假设：暂不做，仅门店端核销）。
