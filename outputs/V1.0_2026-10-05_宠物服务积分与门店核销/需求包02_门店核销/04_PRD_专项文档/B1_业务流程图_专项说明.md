# B1 业务流程图 — 门店核销

## 一、核销主流程

```mermaid
flowchart TD
  A[用户购买线下服务商品] --> B[订单支付成功]
  B --> C[系统生成核销凭证]
  C --> D[用户到店出示凭证]
  D --> E[门店核销员扫码/输码]
  E --> F{校验:凭证/订单/门店/状态}
  F -- 无效/已核销/错店/已退款 --> G[提示对应异常]
  F -- 通过 --> H[展示待核销信息]
  H --> I[确认核销]
  I --> J[订单更新为已核销]
  J --> K[记录核销时间/门店/人员/订单/商品]
```

## 二、角色参与

| 流程 | 参与角色 |
|------|----------|
| 凭证生成 | 系统（自动） |
| 到店核销 | 用户（出示）、门店核销员（执行）、系统（校验/记录） |
| 记录查询 | 后台运营 |

## 三、异常分支

- 扫码失败 → 手动输码兜底。
- 任何校验不通过 → 拦截并提示，不进入确认核销。
