# A7 字段与规则说明 — 门店核销

## 一、核心字段表

### 1. 核销凭证

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| 凭证 ID | string | 是 | 唯一标识 | V1001 |
| 核销码 | string | 是 | 数字核销码，全局唯一 | 8320 4176 |
| 核销二维码 | string | 是 | 二维码内容（凭证标识） | — |
| 订单 ID | string | 是 | 关联订单 | SO2001 |
| 商品 ID | string | 是 | 关联商品 | P3001 |
| 使用门店 | string | 是 | 凭证对应门店 | S4001 |
| 连锁主体 | string | 是 | 凭证门店所属连锁主体/品牌（用于跨店核销校验） | B1001 |
| 用户 ID | string | 是 | 所属用户 | U10001 |
| 状态 | enum | 是 | 待使用/已核销/已失效/已退款 | 待使用 |

### 2. 核销记录

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 记录 ID | string | 是 | 唯一标识 |
| 凭证 ID | string | 是 | 关联凭证 |
| 核销时间 | datetime | 是 | 核销时刻 |
| 实际核销门店 | string | 是 | 实际执行核销的门店（跨店核销时 ≠ 凭证原门店） |
| 凭证原门店 | string | 是 | 凭证对应的原始门店 |
| 核销人员 | string | 是 | 门店核销员 |
| 核销订单 | string | 是 | 订单号 |
| 核销商品 | string | 是 | 商品名/ID |

## 二、校验规则

| 规则 | 说明 |
|------|------|
| 唯一性 | 核销码全局唯一，凭证与订单一对一 |
| 幂等 | 同一凭证只允许一次成功核销 |
| 连锁匹配 | 凭证「连锁主体」= 当前核销门店「连锁主体」（允许连锁互核） |
| 订单状态 | 仅「已支付且未退款/未取消」可核销 |
| 商品类型 | 仅线下服务商品生成核销凭证 |

## 三、待确认字段规则

- 核销码有效期/过期字段：待确认。
- 核销码短信发送：待确认。
- 撤销核销能力：待确认。
