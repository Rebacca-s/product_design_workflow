# 原型说明文档 — 门店核销

## 1. 页面清单与跳转关系

```
用户端：
  订单详情 → 核销凭证页(P1)

门店小程序：
  登录(P2) → 核销首页(P3)
             ├── 扫码 → 待核销信息(P4) → 核销结果(P5)
             └── 手动输码 → 待核销信息(P4) → 核销结果(P5)

后台：
  门店核销 → 核销记录(P6)
```

## 2. 设计目标

- 用户端：凭证清晰、可快速出示。
- 门店小程序：极简「扫码→校验→核销」三步，无培训成本。
- 后台：核销记录可查，支撑结算与经营数据。

## 3. 页面设计说明（摘要）

完整结构见 `04_PRD_专项文档/A6_页面与交互说明_专项说明.md`。核心页面：

- **P1 核销凭证页**：二维码大图 + 数字核销码 + 商品/门店/状态标签 + 复制码。
- **P3 核销首页**：「扫码核销」主按钮 + 「手动输入」兜底入口。
- **P4 待核销信息**：用户/商品/订单/状态 + 确认核销。
- **P5 结果页**：成功/已核销/无效码/非本门店/订单异常等分支。

## 4. 关键交互

- 扫码为主路径，失败可切手动输码。
- 任何校验失败拦截并提示，不进入确认。

## 5. 状态覆盖

首次进入 / Loading / 正常 / 空状态 / 已核销 / 异常 / 成功 七态已定义（见专项）。
